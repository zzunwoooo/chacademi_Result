# 무한의 탑 사용 허가 목록

플러그인(InfiniteTower)이 켜질 때 이 브랜치의 `allow.txt` 를 읽어, 그 서버의 아이피가 목록에 있을 때만 켜진다.

- 추가: `bash tools/add.sh "<줄>" "<메모>"` → 커밋·푸시 (줄은 판매자 쪽 도구가 만들어 준다)
- 취소: `allow.txt` 에서 그 줄을 지우고 커밋·푸시 (그 서버는 다음에 켤 때부터 막힌다. 최근에 허가받은 서버는 목록을 못 읽는 경우에 한해 72시간까지 그대로 켜진다)
- 목록에는 아이피 그대로가 아니라 바꾼 값만 적혀 있다. 메모(`#` 뒤)는 누구 것인지 알아보는 용도.
