## 다시 만들 때

스크립트는 출력 경로가 `/mnt/user-data/outputs/`로 박혀 있음. 필요하면 경로만 바꿔서 실행.

```bash
cd tools/models
python3 models.py            # 까마귀·피냐타·운석 (기본 + shiny도 같이 나옴, shiny는 버리면 됨)
python3 models2.py           # 나머지 10종. 특정 모델만: python3 models2.py grim_reaper disco_ball
python3 render.py <파일.bbmodel>   # preview.png 렌더 확인

cd ../motion
python3 build_spec.py && python3 motion_gen.py forced_dance_spec.json <출력폴더>
```

필요 패키지: Python3 + numpy + Pillow. 모션 검증 스크린샷(`shot.mjs`)은 Node + Playwright.

## 전체 점검에서 찾아 고친 것 (2026-11-16 19:30) — 플러그인 0.8.0 · 모드 0.8.2
코드를 다른 눈으로 한 번 더 읽혀 찾은 것들. 전부 "접속자가 있어야만 드러나는" 종류라 서버 부팅 시험으로는 안 보였다.
- **서버를 끌 때 저장이 빠지던 문제**: 꺼지는 중(onDisable)에는 모드로 신호를 보낼 수 없는데 보내려다 오류가 나서, 그 뒤의 정리와 장부 저장이 통째로 건너뛰어졌다 (마지막 자동 저장 이후 최대 5분치 다이아 기록 손실). → `Net.send` 는 꺼지는 중이면 안 보냄, onDisable 은 저장을 맨 먼저 + 정리를 하나씩 감쌈 + 끝에 한 번 더 저장.
- **인벤토리가 가득이면 다이아가 안 주워지던 문제**: 줍기 이벤트를 "자리가 있을 때만 불리는 것"에서 `PlayerAttemptPickupItemEvent`(자리와 무관)로 바꿈.
- **우편에 들어간 인챈트북이 빈 책으로 나오던 문제**: 우편 종류 `stack` 추가 (아이템을 통째로 적어 둠). 우편에 한글 이름표(`label`, 상점 상품 이름)도 저장. 이름을 모르는 게임 아이템은 `{item:minecraft:xxx}` 로 보내고 모드가 게임의 아이템 이름으로 바꿔 보여 준다 (모드 없는 사람에게는 영어로).
- **치지직 후원 개수**: `DonationEvent.getAmount()` 는 별풍선·치즈 모두 100원 단위 개수 (플러그인 내부: SOOP 단가 100, 치지직 단가 1, getCount = amount×100÷단가). 치즈를 100 으로 한 번 더 나누던 것을 없앰. `donation.chzzk-won-per-unit` 설정 삭제. **실제 치즈 후원으로는 확인 못 함.**
