# 기획에서 아직 비어 있는 것 (2026-11-16 검토)

`events.md` 는 후원 이벤트 표다. 그 이벤트가 올라탈 서버 기본 규칙은 어디에도 적혀 있지 않다.
답을 받으면 이 파일에서 지우고 `events.md` 나 새 기획 문서에 옮긴다.

## 먼저 답이 필요한 것

- [ ] 방송 날짜, 서버를 어디에 올릴지
- [ ] 목표 다이아: 시작값 / 세는 법(들고 있는 수인지 납품인지) / 4명 공동인지 각자인지 / 채우면 무슨 일이 생기는지
- [ ] 이벤트 대상: 후원 받은 스트리머 본인인지 4명 중 랜덤인지. 10개(밥)·300개 연출·4444 즉사는 대상이 안 적혀 있음
- [ ] 맵: 일반 야생인지 전용 광산 맵인지
- [ ] 3000 의 "다이아 폭탄"이 무엇인지
