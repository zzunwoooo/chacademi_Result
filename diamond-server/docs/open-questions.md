## 정해진 것 (오너 답)

- 깨굴서버와는 별개의 서버. 깨굴 기능(가챠·감옥·카지노·땅·농사 등)은 넣지 않는다
- 캔 다이아는 인벤토리 대신 화면의 보유 다이아 숫자로 들어온다
- 상점: 보유 다이아로 구매·판매. 상품 = 곡괭이, 곡괭이용 인챈트북, 전용 아이템(밥·인벤세이브권·귀환권·텔레포트권)
- 런처 이름 = 나니 다이아서버
- **처음 목표 = 1000개** (모두 같은 값). 이벤트·상점 수치는 이 기준에 맞춘다
- 목표를 다 채우면 **졸업 알림만** 띄운다 (그 뒤로 달라지는 것 없음)
- 이벤트 대상: **100개 장난만 랜덤**(룰렛으로 1명 또는 전원), 나머지는 후원 받은 본인
- 맵: 일반 야생
- 다이아 폭탄 = 많은 양의 다이아 드랍 + 펑 터지는 효과음·연출
- UFO 모델은 Claude 가 만든다 (만듦: `models/farm_ufo_beam.bbmodel`, 생성기 `tools/modelgen/UfoGen.java`)
