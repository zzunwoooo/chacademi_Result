# 후원 이벤트 기획 (확정본)

별풍선 개수 → 이벤트. 4인 서버 기준. 랜덤 풀은 직전에 나온 이벤트를 다음 한 번 제외한다.

## 100개 장난 풀

1명 랜덤 대상은 타겟 룰렛(스포트라이트가 4명 사이를 돌다 멈춤)으로 뽑는다.

**1명 랜덤**
- 다이아 도둑 까마귀: 다이아 64개 묶음(없으면 가장 큰 묶음)을 물고 도망. 잡으면 되찾음
- 조작 반전: 30초간 이동 조작 반전 (클라 모드 필요)
- 개미화: scale 0.2
- 로켓 발사: 100칸 위로 발사, 꼭대기에서 겉날개 자동 장착, 착지 후 회수
- UFO 납치: UFO 빔에 빨려 올라가 3초 갇힌 뒤 반경 300칸 아무 데나 떨어짐
- 모루 낙하: 3초 뒤 떨어지는 모루를 피해야 함. 맞으면 5초 기절
- 저주받은 곡괭이: 1분간 다이아가 석탄으로 나옴
- 스토커 크리퍼: 15초간 투명 크리퍼가 따라다니며 "쉬익" 소리만 냄 (안 터짐)
- 강제 댄스: 10초간 조작 불가, 춤 모션 재생
- 핫바 셔플: 핫바 아이템 위치 섞기
- 인벤토리 칸 봉인: 30초간 가방 9칸이 막혔다가 원래 물건이 돌아옴
- 몬스터 습격: 45초간 할로윈 몬스터 3~5마리(20종 중 무작위)가 그 사람만 노림. 원거리·돌격·암살자마다 스킬이 다르고 빨간 예고가 먼저 보임

**4명 전체**
- 자리 셔플: 4명 위치를 랜덤으로 바꿈
- 정전: 30초간 화면 암전 + 워든 심장 소리
- 바닥은 마그마 블럭: 서 있는 블럭이 마그마로 바뀌어 계속 움직여야 함
- 강제 바니홉: 30초간 계속 점프
- 단체 UFO 납치: 4명을 각자 다른 곳에 떨어뜨림

## 300개 다이아 연출 풀

어떤 게 걸려도 기대값이 다이아 80~120개 근처가 되게 맞춘다.

- 다이아 소나기: 구름에서 다이아 약 100개가 5초간 쏟아짐
- 미다스의 손: 10초간 밟는 블럭이 다이아 광석으로. 종료 시 안 캔 광석 대부분은 돌로 복원
- 다이아 피냐타: 30초 안에 50대 때리면 터지며 다이아 약 150개, 실패 시 0개
- 다이아 분수: 발밑 분수대에서 다이아 약 70개가 솟구침
- 운석우: 착탄 지점 반경 2~3칸이 다이아 광석으로
- 거인화: 30초간 scale 2, 한 번 캘 때 3x3 파괴

## 1000개 룰렛 상품 (확률)

목표 -300 (10%) · 목표 +300 (10%) · 목표 ±100 랜덤 (20%) · 다이아 200개 (10%) · 300 풀 3연속 (15%) · AI 플레이어 소환 (15%) · 인벤토리 다이아 반토막 (10%) · 꽝: 밥 3개 (10%)

## 2000개 후원자 AI 플레이어

Citizens NPC에 후원자 닉네임+스킨. LLM·채팅 없음, 플러그인에서 직접 짠 행동 루프:
따라다니기(2~3칸 뒤) → 1~2초마다 반경 8칸 광석 스캔(다이아 우선) → 길 찾아 이동·채굴(막히면 파고 감) → 다이아는 스트리머 인벤으로 즉시 전달 + "+1 다이아" 표시 → 멀어지거나 끼면 스트리머 옆으로 텔레포트 → 3분 뒤 퇴장. 동시 최대 3명, 같은 광석 중복 방지(찜).

## 3000개 채팅 투표

30초간 방송 채팅의 1/2를 집계. 1이 많으면 다이아 폭탄, 2가 많으면 번개와 함께 즉사.
