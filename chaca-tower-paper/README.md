- 나가기 처리 순서: HuskSync·MagicCodexBridge 가 LOWEST 에서 저장하므로 ChacaTower 의 나가기 처리기를 같은 LOWEST 맨 앞에 둔다 (TowerPlugin.quitFirst, 켜질 때 로그로 순서 출력). 안 그러면 접속 끊김 때 탑 소지품(빈 가방)이 공용 DB 에 저장됨.
- 체력·이동속도: 바깥 보정(장신구 PDC·펫 도감 체력·아티팩트)이 남아 있어도 최종값을 20 + 탑 보너스로 고정 (tick 마다).
- 펫: 들어갈 때·tick 마다 MCPets 펫과 동행 펫을 들여보냄 (브리지 비공개 메서드 리플렉션).
- 입장 때 흡수 체력·불·얼음·화살·낙하 거리도 비움. 나갈 때 체력은 맡긴 값 그대로 (공짜 회복 없음). 방 안에 떨어진 아이템은 끝날 때 치움.
- 명령은 허용 목록만 (탑·친구·채팅·화면·자동시전 등). 배낭·우편·상점 등 소지품이 바뀌는 명령은 전부 막힘.
- 남은 것: 마나 최대치·시전 속도(장신구·펫) 는 그대로. 지능은 피해 환산 방식 그대로.
