# ChacaTower — 무한의 탑 (1인 로그라이크, 2026-11-09)

학교 서버 던전 월드의 전투방 하나를 50개 층이 같이 쓴다. 한 번에 한 명, 나머지는 대기열.

## 흐름
1. `/탑 입장` (입구 반경에 가면 안내가 뜸) → 던전 입장권 1장.
2. 소지품·경험치·효과를 `plugins/ChacaTower/stash/<uuid>.yml` 에 맡김 (파일이 남아 있으면 다음 접속 때 돌려줌).
   장착 아티팩트(PDC `magiccodexbridge:artifact_equipped`)도 맡겼다가 돌려놓음.
3. 배운 마법은 권한 덧붙임(attachment)으로 전부 false → 탑에서 배운 것만 true. 디스크에 안 남아 서버가 꺼져도 원래 마법 그대로.
4. 시작 카드 = 기본 공격 마법 3장 (공격 마법 중 1서클, 10% 확률로 다른 마법).
5. 층: 카운트다운 → 몹 (15층부터 두 무리) → 다 잡으면 증강 카드 3장 중 1장 (다시 뽑기 1회).
6. 쓰러짐·포기(`/탑 포기`)·방 이탈·접속 끊김 → 끝. 맡긴 것 돌려주고 탑에서 얻은 것은 모두 사라짐. 기록 = 깬 층 수 + 시간.

## 지능
브리지 지능은 건드리지 않는다. 탑 몹에게 준 피해를 `(40 + 탑 지능) / (40 + 원래 지능)` 배로 맞춤
(탑 지능 = `start-intelligence` + 지능 카드). 원래 지능에는 마법봉·장신구·발견 보너스가 다 들어 있음.

## 몹
- 기존 미몹 (config `mobs.normal` 25종 · `mobs.elite` 30종). 체력·공격력은 층 배율로 덮어씀 (`balance`).
- 10층마다 수문장 (정예 ×5 체력, 보스바). 층별 보스는 오너가 나중에.
- 특성 8종: 신속 6 · 보호막 11 · 흡혈 16 · 분열 21 · 폭발 26 · 광폭 31 · 재생 36 · 가시 41 (층부터).

## 카드 (등급 일반·고급·유일·전설, 높은 층일수록 높은 등급)
마법 습득 · 지능 · 최대 체력 · 회복 · 방어구 · 음식 · 포션 · 탑의 유물(9종) · 마력 증폭 · 마력 방벽 · 생명 흡수 · 바람걸음 ·
승전의 숨결 · 사냥꾼의 갈증 · 불사조의 깃털 · 저주받은 힘 · 행운의 주사위 · 다시 뽑기 · 시련의 서약 · 도박사의 내기.
원래 아티팩트는 DB 보유 기록이라 탑 안에서 주고 빼기가 위험 → 탑 안 전용 "탑의 유물" 로 대신함.

## 설정 (OP)
`/탑관리 설정도구` (블록 좌클릭 = 방 모서리1, 우클릭 = 모서리2) · `/탑관리 시작` · `/탑관리 출구` · `/탑관리 입구` (지금 자리) ·
`/탑관리 상태` · `/탑관리 다시불러오기` · `/탑관리 강제종료` · `/탑관리 층 <번호>` (시험용).
보상: `/탑관리 보상` 창 → 칸을 눌러 상자를 열고 아이템을 넣고 빼면 닫을 때 저장 (rewards.yml).
- 도달 보상 5·10·…·50층: 판이 끝날 때 깬 층 기준 가장 높은 구간 하나 (쓰러져도·포기해도).
- 첫 도달 10·20·30·40·50층: 사람마다 한 번 (넘은 것 모두).
- 수문장: 잡을 때마다 확률(좌/우클릭 ±5%), 판이 끝난 뒤 지급.
지급 = MagicCodexBridge RewardDelivery (가방, 넘치면 우편). 입장창 보상 칸 3개(도달·수문장·첫 도달)에 그대로 보임.

- 펫: 들어갈 때·tick 마다 MCPets 펫과 동행 펫을 들여보냄 (브리지 비공개 메서드 리플렉션).

- 명령은 허용 목록만 (탑·친구·채팅·화면·자동시전 등). 배낭·우편·상점 등 소지품이 바뀌는 명령은 전부 막힘.
- 장신구 4칸(플레이어 PDC accessory_slot_0..3)도 아티팩트처럼 맡겼다가 돌려준다 (Magic.snapshot 글자에 같이). 벗긴 뒤 브리지 refreshStats 로 능력치 다시 계산.
- 마나: ManaService 수정자 chacatower:tower 하나로 최대치·초당 회복을 start-mana / start-mana-regen 으로 고정 (tick 마다). 나갈 때 푼다.
- 마나 회복은 규칙대로 최대치의 10% (start-mana-regen 0 = 자동). 시작 물건 = 즉시 회복 투척 포션 3개 (start-potions), 빵 없음.
- 배고픔 무한 (FoodLevelChangeEvent 취소), 자연 회복 없음 (SATIATED 취소). 포션·카드 회복은 됨.
- 첫 카드는 반드시 마법 3장 (기본 공격 마법, 모자라면 다른 공격 마법으로 채움).
- 탑 안 영구 습득 막기: 들어갈 때 LuckPerms magic.learned.* 를 기억, 나갈 때 새로 생긴 것은 lp unset + MagicDiscovery adminSetLearned(false) 로 되돌림 (로그 경고).
- 탑이 준 물건은 PDC chacatower:tower_item 표시. 끝날 때 표시 없는 물건(의뢰 보상 등 바깥에서 들어온 것)은 가방·우편으로 보냄.
- 남은 것: 지능은 피해 환산 방식 그대로.

소지품·능력치 안전
- HuskSync: 판 중인 사람의 저장(BukkitDataSaveEvent)을 취소 → 서버가 갑자기 꺼져도 공용 DB 엔 들어가기 전 소지품이 남는다. 남은 맡김 복구는 HuskSync 불러오기가 끝난 뒤(BukkitSyncCompleteEvent).
- 체력·속도·흡수 체력 수정치를 저장 안 되는 것(transient)으로. **배포 때 5대 HuskSync config `ignored_modifiers` 에 `tower_*` 를 꼭 추가** — HuskSync 3.8.7 은 수정치 목록(transient 포함)을 그대로 긁어 가고, 이름 비교를 열쇠의 뒷부분(`tower_hp`)으로 하므로 `chacatower:*` 가 아니라 `tower_*` 여야 먹는다 (jar 확인).
- 남은 맡김 복구: 가방에 이미 진짜 소지품이 있으면 덮어쓰지 않고 맡김 파일을 `stash/conflict` 에 보관 (덮으면 그 사이 얻은 건 사라지고 쓴 건 복사됨). 장신구·아티팩트는 언제나 돌려놓음. 복구를 기다리는 동안 가방·버리기·줍기 잠금.
- 이전 맡김이 남아 있으면 새로 맡기지 않음 (덮어쓰기 금지). 장신구·아티팩트를 못 돌려놨으면 `stash/magic` 에 남겨 다음 접속 때 다시.
- 탑 안에서 물건 버리기·다른 창 열기 금지, 탑 표시 물건은 탑 밖에서 못 줍고 10초마다 탑 밖 가방에서 지움, 끝날 때 월드의 탑 표시 아이템도 치움.
- 모드 화면 잠금(BridgeLock): 배낭 쪽 넘기기(가방 27칸을 통째로 바꿈)·우편·상점·강화·연금·아티팩트·장신구·펫·의뢰·이동 채널을 판 중인 사람에게만 막음 (config `locked-channels`).
  다른 플러그인의 채널 처리기를 떼고 우리 것을 대신 거는 방식이라, 꺼질 때 반드시 되돌린다 (시작 로그 "탑 안 모드 화면 잠금: 채널 N개").
- 서버가 꺼지는 순간 진행 중이던 판의 보상이 빠지던 것 → 그 자리에서 지급. 입장 때 커서·제작칸 물건이 사라지던 것 → 먼저 가방으로. 바깥에서 받은 음식이 지워지던 것 → 우편으로.
- 피해 이벤트 없는 죽음(/kill 등)도 판 끝으로 처리. 입장권 환불에 탑 표시가 붙던 것 고침.

## 배포 순서 (오너 승인 뒤, 재시작 때)
1. 5대 `plugins/HuskSync/config.yml` 의 `ignored_modifiers` 에 `- tower_*` 추가.

| 위험과 보상 | 유리 대포(피해 +, 받는 피해 +25%) · 피의 계약(피해 크게 +, 맞힐 때마다 체력 1 — 30%까지만) · 배수의 진(체력 30% 이하일 때 받는 피해 -) |
| 층마다 쌓임 | 복리(층마다 피해 +) · 학자의 서(층마다 지능 +) |
| 마나·재사용 | 마나 샘(최대 마나·회복) · 마력 수확(처치마다 마나) · 시간 왜곡(시전 가속) · 재장전(처치 때 대기가 가장 긴 마법 초기화) |
| 번짐 | 연쇄 번개(확률로 옆 몹에게 50%) · 여파(처치하고 남은 피해가 옆 몹에게) · 마무리(체력 낮은 몹 즉시 처치, 수문장 절반) |
| 방어·회복 | 가시 갑옷(맞으면 때린 몹 최대 체력의 %, 수문장 1/3) · 잔상(회피, 최대 45%) · 숨 고르기(3초 안 맞으면 회복, 층마다 상한) · 마력 보호막(층 시작 보호막) |

- 마법 쪽 연결(마나 더하기·시전 가속·재사용 초기화)은 브리지 `ManaService` 의 public 메서드를 쓴다. 메서드가 없으면 그 증강만 조용히 안 되고 로그 한 줄.
- 이미 상한이거나 짝이 없어 효과가 없는 카드(치명타 없이 날카로운 일격 등)는 뽑기에서 빠진다 (`Cards.useless`).
- 지금 탑 최대 마나보다 비싼 마법은 카드로 나오지 않는다 (예전엔 배워도 못 쓰는 죽은 카드였음).

### 내 증강 창 `[기능:탑내증강]`
- `/탑 증강` (탑 안에서) 또는 카드 화면의 「내 증강」 버튼(모드: Tab 키 / 상자 창: 오른쪽 아래 책).
- 모드가 있으면 카드 화면 그림(틀·배경·아이콘)을 그대로 쓴 화면: 왼쪽에 작은 카드로 늘어놓고, 가리킨 칸을 오른쪽에 큰 카드로. 같은 종류는 한 칸에 합쳐서 "지금까지 합계" 를 보여 준다. 맨 앞 칸은 지금 능력 요약.
- 모드가 없으면 상자 창(`BuildMenu`). 카드 고르는 중에 열었으면 닫을 때 카드 창으로 돌아간다.
- 새 그림 파일 없음 (새 증강은 아이템 그림으로 표시).

### 밸런스 (계산: 카드 뽑기는 실제 규칙 그대로, 전투는 단순 모형으로 수천 판 돌림)
- 구조 문제를 고침: ① 피해 기준 오프셋 40 → 12 (서버 공식 base + ratio × 지능 에 맞춤; 예전엔 원래 지능이 높은 사람이 탑에서도 더 셌음) ② 생명 흡수가 위층에서 끝없이 불어나던 것 → 어느 층이든 "한 층을 다 잡으면 흡수율 × 80" ③ 음식 카드(빵·스테이크)가 무효 → 황금 사과 ④ 못 쓰는 마법 카드 제외 ⑤ 시작 마법 2개 (1개로는 1층이 1분).
- 수치: 몹 체력 기준 40·150 → 26·100, 체력 성장 1.02 → 1.025/층, 공격력 0.045·1.012 → 0.03·1.01, 수문장 체력 5배 → 2.0배부터 구간마다 +0.5 (10층이 벽이던 것 완화, 50층이 가장 단단함).
- 증강을 먹었을 때 초당 피해 기대값 (잘 고르는 사람 중앙값): 1층 6 → 10층 15 → 20층 44 → 30층 112 → 40층 288 → 50층 약 800 (운 좋게 겹친 상위 10%는 약 2100). 50층 한 층의 몹 체력 합계는 1층의 약 170배.
- 결과 모양: 한 층 15~45초. 잘 고르는 사람은 중간 25층쯤, 넷 중 하나가 50층 완주. 완주하는 판은 30층 뒤로 거의 안 맞는다 (잘 겹치면 쉽게 끝까지). 아무거나 고르면 10층 수문장 앞뒤.
- ★ 절대 난이도는 "몹에게 얼마나 자주 맞느냐" 가정에 달려 있어 한 번 해 봐야 맞출 수 있다. 너무 아프거나 안 아프면 `normal-damage`·`elite-damage` 두 값만 같은 비율로 고치면 된다.
- 계산 프로그램: `hb2/n1112/tower/balance/S3.java` (실행: `java S3.java 2000 final`, 같은 폴더에 spell-runtime.yml·mana-spells.yml).

### 11/12 최종 점검 (새 코드만 처음 보는 눈으로 한 번 더) 에서 고친 것
- 마법 보호 검사용 "피해 0" 신호에 되갚기·연타·피의 계약·가시 갑옷·잔상이 헛발동하던 것 → 피해 0 은 건너뜀.
- 연쇄 번개·여파·가시 갑옷·메아리 수정의 추가 피해가 몹의 무적 시간(방금 맞은 뒤 0.5초)에 먹히던 것 → 잠깐 풀고 넣음 (`pierce`).
- 카드가 바뀐 직후 0.4초 동안의 클릭·숫자 키는 무시 (앞 카드를 두 번 누르면 다음 카드까지 골라지던 것 — 시작 마법 2개라 매판 생길 수 있었음).
- 마무리: 몹 보호막까지 보고 판정, 걸리면 확실히 처치. 넘치는 마력: 시전 직전 마나로 판정 (최근 1초 안 최고값).
- 저주받은 힘을 여러 번 골라도 최대 체력이 하트 2칸 밑으로 안 내려감, 마지막 층을 깬 tick 의 오류 1회, 내기+서약을 같은 차례에 고르면 내기 보상이 사라지던 것(내기를 걸면 서약이 안 나옴).
- 그대로 둔 것: 시전 가속은 원래 계정에 붙은 가속(있다면) 위에 더해진다 (마나처럼 고정하지 않음).
