# ChacaGimmick — 던전 기믹 플러그인

던전 기믹 모델 37종(`models/` 의 bbmodel)을 **MythicMobs 없이** 블록 단위로 설치한다.
모델·애니메이션·크기는 **ModelEngine 4** 가 그리고, ItemsAdder 는 ModelEngine 리소스팩을 합쳐 보내기만 한다.

**2026-10-24 개편 (오너 결정):** 퍼즐·노드·`puzzles.yml` 을 없앴다. 기믹은 각자 정해진 사용법대로만 동작하고,
**붙어 있는 블럭끼리 자동으로 연결된다** (레드스톤처럼). 명령은 소환하고 막대로 고치는 것뿐이다.

## 설치

1. `chaca-gimmick-<버전>.jar` → `plugins/`
2. `models/<id>.bbmodel` 37개를 `plugins/ModelEngine/blueprints/` 에 넣고 `/meg reload` (blueprint 이름 = 모델 id).
   ModelEngine 리소스팩을 ItemsAdder 병합 목록에 넣고 `/iazip`.
3. 마법 연동(화로·비석·터빈, 기믹 마법 239~250)을 쓰려면 `ChAcademiaMagicMythic` 도 설치.
4. 서버 시작 → `plugins/ChacaGimmick/` 에 `config.yml`, `models.yml` 생성. 예전 `puzzles.yml`·`puzzle-state.yml` 은 더 이상 읽지 않는다 (지워도 됨).

## 명령

```
/던전관리 소환 <모델>       내가 서 있는 칸에 설치 (내가 보는 방향)
/던전관리 도구              기믹 막대 받기
/던전관리 목록 [검색]        설치된 기믹
/던전관리 모델 [검색]        모델 목록 (입력·출력·도관 구분 표시)
/던전관리 초기화 [반경]      주변 기믹을 처음 상태로 (기본 32칸): 문 닫힘, 레버 내림, 화로 꺼짐, 얼음 다시 얼림, 발판 제자리
/서버관리 새로고침 던전      config·models.yml 다시 읽기
```

## 기믹 막대 (블레이즈 막대)

모델을 클릭하거나, 바라보고 허공을 클릭한다.

| 조작 | 동작 |
| --- | --- |
| 우클릭 / 좌클릭 | 현재 모드에서 + / − |
| 웅크리고 우클릭 / 좌클릭 | 다음 / 이전 모드 |

모드: **정보** → **회전**(90°) → **크기**(0.1) → **이동**(보는 방향 1칸) → **높이**(1칸) → **정답** → **삭제**(우클릭 두 번)

- **정보**: 켜짐/꺼짐, 연결된 입력·출력, 도관 신호 흐름.
- **정답**: 맞춰야 켜지는 장치의 목표값. 수위 기둥(수위 0~3, 기본 3), 회전 다이얼(위치 0~3, 기본 2),
  잠든 석상(바라봐야 하는 방향, 기본 = 처음 놓인 방향의 반대), 빛 수신 수정(받아야 하는 색, 기본 아무 색),
  부유 발판(움직일 길: 앞으로/위로 2·4·6·8칸, 기본 앞으로 4칸).

## 연결 규칙

- **입력** 블럭이 켜지면, 그 블럭에 **붙어 있는** 출력 블럭으로 신호가 간다 (위·아래·옆 6면).
- 멀리 있으면 **마력 도관**(직선·코너·분기)을 깔아 잇는다. 도관은 포트 방향으로만 이어지고, 막대 회전이나 249 도관 회전으로 방향을 바꾼다.
- **출력** 블럭은 이어진 입력이 **전부 켜지면** 열린다. (화로 두 개가 문 하나에 이어져 있으면 둘 다 켜야 열림)
- 입력끼리는 신호를 넘기지 않는다. 거울·프리즘은 빛줄기(244)에만 쓰인다.

### 입력 — 켜지는 조건

| 기믹 | 켜지는 조건 |
| --- | --- |
| 스위치 레버 | 우클릭할 때마다 켜짐/꺼짐 |
| 대지 압력판 | 누가 밟고 있는 동안 (168 그림자 분신 포함), 242 무게추 → 10초 |
| 원소 화로 | 화염 마법·35 다시 타오르는 불로 켜짐, 물 마법·48 심지 줄이기로 꺼짐 |
| 원소 비석 (6속성) | 같은 속성 마법이 닿으면 켜짐 (초기화 전까지) |
| 얼음 봉인 결정 | 239 해빙의 열기로 녹이면 켜짐 (초기화 전까지) |
| 씨앗 화분 | 243 덩굴 깨우기 → 켜짐, 앞 칸에 타고 오르는 덩굴 (초기화 전까지) |
| 증기 밸브 | 240 증기 점화 → 6초 |
| 풍차 터빈 | 바람 마법 → 10초 |
| 물레방아 | 아래로 물이 흐르는 동안 (72 수맥 개방 등) |
| 빛 수신 수정 | 빛줄기(244)가 정답 색으로 닿는 동안 |
| 수위 기둥 | 수위(241)가 정답과 같을 때 |
| 회전 다이얼 | 위치(245)가 정답과 같을 때 |
| 잠든 석상 | 방향(247)이 정답과 같을 때 |

### 출력 — 열리는 동작

| 기믹 | 동작 |
| --- | --- |
| 봉인문 (대형·소형) | 열림 (초기화 전까지) |
| 시간차 문 | 8초 열렸다 닫힘 (입력이 다시 꺼졌다 켜지면 또 열림) |
| 봉인 보물상자 (6속성) | 열림 (초기화 전까지) |
| 빛의 다리 | 나타나 밟을 수 있음 (초기화 전까지) |
| 부유 발판 | 정답 길만큼 한 번 이동 (초기화 때 제자리) |
| 물길 수문 | 입력이 켜져 있는 동안 열림 |
| 바람 분출구 | 입력이 켜져 있는 동안 위에 선 사람을 띄움 |
| 원소 텔레포트 게이트 | 입력이 켜져 있는 동안 열림. 같은 입력에 이어진 다른 게이트로 이동 (걸어 들어가거나 우클릭). 250 차원 표식으로도 이어짐 |

## 블록 단위 설치와 배리어

- 기믹은 블록 격자에 놓인다: 앵커 블록 + 방향(남·서·북·동). 차지하는 칸은 `models.yml` 의 `footprint [가로, 깊이]`.
- `collision`: solid = 차지한 칸을 배리어로 막음, platform = 한 층만(밟고 다님), floor·none = 안 막음.
  문·수문·얼음 봉인은 열리면 배리어가 걷히고, 빛의 다리는 열려야 밟힌다.
- 배리어는 빈 칸에만 놓고, 우리가 놓은 블록(`collision.yml`)만 지운다.

## 저장 파일

| 파일 | 내용 |
| --- | --- |
| `gimmicks.yml` | 설치한 기믹 (모델·월드·앵커 블록·방향·크기·장치 상태·정답·켜짐) |
| `collision.yml` | 모델이 차지한 칸에 놓은 배리어·덩굴 기록 |
| `solids.yml` | 예전 퍼즐 방벽 기록 — 남아 있으면 청크가 로드될 때 걷어내고 비운다 |
