## PetPaw 사용법 (모드 연결)
- 동행 펫이 버프/스킬을 쓸 때 펫 발밑 바닥(P = 발 위치, 바닥 높이)에 1회 재생. static, one-shot, 런타임 입력 없음(위치 + 서버 수평 방향만).
  - `claude:petpaw/circle` — 기본 펫: 금빛·연분홍.
  - `claude:petpaw/circle_shiny` — 변색종 펫: 청록·보랏빛 (모양·타이밍 동일, 재질/색만 다름).
- 길이 약 1.2 s (마지막 입자 ~1.15 s 에 사라짐), emission 0.6 s 뒤 자동 종료. stop 신호 불필요.
- 마법진 지름 약 1.6 m (바깥 링 반경 0.79 m): 바깥 이중 링 + 발자국 문양 룬 띠(역회전) + 안쪽 링과 작은 원 8개 + 가운데 강아지 발바닥(패드 1 + 발가락 4, PNG, 약 0.72 m).
  - 0 ~ 0.25 s: 마법진이 0.6 → 1.04 → 1 로 살짝 퍼지며 나타남, 충격 링 1회, 작은 섬광(0.26 s), 0.1 s 발바닥 찍힘 + 메아리.
  - 0.25 ~ 0.85 s: 링·룬 띠가 서로 다른 속도로 회전, 반짝이 8개·빛 알갱이 12개가 위로 떠오름.
  - 0.85 ~ 1.15 s: 1.1배로 살짝 퍼지며 사라짐.
- 발바닥 발가락은 static 기준 +Z(서버가 넘겨주는 펫의 수평 정면) 쪽을 향함. 펫 크기 무관 고정 크기(작은 펫 기준).
- 입자 수: 시스템당 약 29개(메시/쿼드 9 + 반짝이 8 + 알갱이 12). 텍스처 11장, RGBA 약 1.5 MiB (두 시스템 공유).
