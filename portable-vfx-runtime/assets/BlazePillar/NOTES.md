# BlazePillar — converter notes (블레이즈 전용 "화염 기둥")

- 시스템 1개: `erupt` (role static, one-shot, duration 1.0 s, 마지막 연기·불씨 ≈2.5 s). P = 대상 발밑 지면 중심, +Y 위. 방향(yaw) 무관.
- 반경 R = 3 m 기준. 런타임 `areaRadius` (SCENE.scale, reference 3, factor 0.5–2.0) 로 실제 장판 반경에 맞춤.
- 타임라인: t=0 지면 마법진(링·팔각성·룬띠·중앙 문장) 점화 + 수축 링 → **T0 = 0.12 s 분출**(섬광·충격파 2겹·불기둥 튜브 2겹·나선 리본·블레이즈 막대 회전·스파크·숯 파편) → 0.6–1.1 s 기둥 수축 → 연기·불씨·그을음 2.5 s 소멸.
- 서버는 빨간 예고 장판(모드 텔레그래프)이 끝나기 0.1 s(2틱) 전에 이 효과를 재생하면 분출 순간이 피해 판정과 맞음.
- 지면 전용 스킬(벽/공중 시나리오 없음). 빨간 예고는 이 팩에 없음 — 모드(TelegraphRenderer)가 그림.
- 색 변형 몹: EffectRequest tint 로 재색 가능(가산 재질 위주).
