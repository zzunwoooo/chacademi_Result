# LoosenGrasp (손아귀 풀기) — 변환 메모 (REDO 2026-10-25)

시각 연출만 담는다. 플레이어 핫바 무작위 변경, 몬스터 무장해제(공격·마법 모두 불가) 4초, 판정·마나 60·쿨타임 20초는 외부 게임 기능.

**배치**: 네 시스템 모두 `role: attached`, **대상(TARGET)** 에 붙는다 (anchor = 대상 발, facing = 대상 몸 방향, +X = 대상 오른쪽). `scale` targetHeight = 대상 키, s = clamp(h/1.8, 0.6, 2.5).

| 시스템 | 언제 시작/정지 |
|---|---|
| `hand_ripple` | 적중 순간, 플레이어·몬스터 공통. 오른손 부근(기준 키 1.8 m에서 [0.34, 1.02, 0.30])을 얇은 회백색 파장이 한 번 스치고, 어긋난 화살표 잔상이 손끝을 지나간다. ~0.45 s 후 끝. |
| `mark_begin` | 몬스터에게 무장해제가 걸린 순간 (hand_ripple과 거의 동시). 머리 위 표식 두 조각이 맞물리며 짧게 번쩍. 일회성. |
| `mark` | 같은 순간 시작, loop. 무장해제가 유지되는 동안 머리 위(+2.18 m) 작은 '끊어진 공격(검)·마력(별)' 표식을 유지. **상태 종료 시 모드가 stop** (onStop 0.12 s로 즉시 정리). |
| `mark_break` | 상태 종료(또는 해제) 순간 시작. 표식이 좌우 두 조각으로 갈라져 작은 조각·먼지로 흩어짐. 일회성. |

- 플레이어 대상: `hand_ripple` 만 재생. 슬롯 변경 후 아이템은 게임 렌더링 그대로 — VFX는 무기 모델·아이템을 만들지 않고, 슬롯 잠금 연출도 없다.
- 몬스터 대상: `hand_ripple` + `mark_begin` + `mark` → 종료 시 `mark` stop + `mark_break`. 유지 시간은 시스템이 아니라 실제 상태 지속에 맞춘다 (4초는 기획값, 미리보기만 4.0 s에 종료).
- 대상이 죽거나 사라지면: 모든 인스턴스 stop + local 레이어 정리 (world 레이어 먼지는 자연 소멸).
- 사슬·속박·이동 봉쇄·연기·구체·폭발·마법진 없음.
- 클라이언트 미지원 기능 사용 없음 (phasedSequence도 쓰지 않음 — 시작/정지는 상태 이벤트로).

## REDO 2026-10-25 — 바뀐 연출 (시스템 id·역할·loop·duration·scale·시작/정지 규칙 그대로)
| 시스템 | role | loop | duration | 비고 |
|---|---|---|---|---|
| hand_ripple | attached (대상) | false | 0.2 | 약 0.45 s 후 끝 |
| mark_begin | attached | false | 0.1 | +0.08 s 섬광 |
| mark | attached | **true** | 1 | 상태 종료 시 stop (onStop 0.12) |
| mark_break | attached | false | 0.05 | 약 0.55 s |
- 머리 위 표식: 공중에 뜬 평면 아이콘(검·별)을 없애고, 끊어진 6조각 라인 링 3개(수평 1 + 교차 수직 2 = 혼천의 구) + 룬 띠 + 풀린 손 시길 원판으로 만든 **무장해제 구체**를 머리 위(+2.18 m)에 띄웠다. 어느 방향에서 봐도 보인다. 유지는 수명 1.2 s 조각 2개가 삼각 알파로 교차 재생되고, 6각 대칭이라 회전이 맞물려 끊김 없이 이어진다. 잉크 방울이 떨어지고 모트가 돈다. 양손에는 저림 불꽃과 잉크 연기를 약하게 넣었다.
- mark_begin: 링 3개와 룬 띠가 크게 조여들며 들어오고, 별·충격 링·불꽃·잉크 조각·양손 섬광이 터진다. mark_break: 링이 회전하며 퍼지고 흩어지며 섬광·조각·먼지·링이 남는다.
- hand_ripple: 오른손목을 조였다가 앞으로 빠져나가는 라인 링, 손을 감았다 풀리는 나선 와이프 2줄(잉크 사본 포함), 옆으로 스치는 화살 잔상 3개(슬롯 변경), 별, 불꽃, 잉크 조각, 모트.
- 2차 수정 (2026-10-25): hand_ripple에 손을 움켜쥐었다가 **비틀어 여는 잉크 갈퀴손**(위·아래 두 쌍, 옆과 정면 두 평면, 잉크 몸체와 보라 테두리 빛 사본)을 넣었다. 오른 팔뚝에 끊어진 쥠 시길 링 2개가 조였다가 산산이 터지고(+0.16 s), 조각과 불꽃이 흩어진다. mark는 양 팔뚝에 끊어진 쥠 링 4개(교차 재생, 6각 대칭)와 떨어지는 잉크 조각을 유지한다. 머리 위 표식은 반경 0.42 m로 키우고 링을 두껍게 했으며, 잉크 코어, 빛, 위로 솟는 줄기, 모트 2배를 넣었다. mark_begin은 팔 링이 조여 붙고, mark_break는 팔 링도 함께 터진다. 모든 burst는 각 시스템 duration 안에 있다.
