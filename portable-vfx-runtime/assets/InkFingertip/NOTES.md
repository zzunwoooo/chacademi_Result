# InkFingertip (183 먹물 손끝) — 변환 메모 (REDO 2026-10-25)

**언제**: 염료 선택 확정 → 제작 성공 이벤트 때 1회만 재생. UI 선택 전·취소 시에는 재생하지 않는다. 선택 UI, 64개 지급, 마나 30, 쿨타임 120초, 획득 조건(염료 제작 누적 10회)은 모두 외부 기능.

**시스템 16개 = 염료 16색** (`ink_white, ink_light_gray, ink_gray, ink_black, ink_brown, ink_red, ink_orange, ink_yellow, ink_lime, ink_green, ink_cyan, ink_light_blue, ink_blue, ink_purple, ink_magenta, ink_pink`).
모드는 선택된 염료의 시스템 **하나만** 시작한다(무지개 동시 재생 없음). 모두 동일한 연출·타이밍, 텍스처 공유, 색만 다름.
- `role: attached`, 시전자 발(anchor) + 수평 방향(facing). 손바닥 위치는 시전자 기준 오프셋 (+0.36, 1.10, +0.45) m (오른손을 앞으로 내민 자세 가정). 손에 직접 붙이는 입력은 클라이언트에 없음 → 발 기준 고정 오프셋.
- 길이 ~1.3 s, `loop:false`, 방출 0.85 s.

**타임라인** (REDO 2차): 0.00 손끝 (0.36, 1.16, 0.6)에서 잉크 리본이 솟아 감기며 위쪽 공중 구슬 자리 (0.36, 1.46, 0.6)로 빨려 들고, 그 아래 서예 시길 고리(메시 라인+필기체 띠)가 그려짐, 손끝에 어두운 먹물 튐 · **0.22** 주먹만 한 잉크 구슬 형성(본체 알파+하이라이트), 0.28/0.34 고리 2개가 구슬을 돌고 반짝임·입자 · 0.45–0.78 구슬이 출렁이며 떠 있음 · **0.78** 터짐: 섬광·파동 2겹, 염료 방울 22개가 튀어 손 쪽으로 떨어지고 방울 비, 어두운 먹물 튐, 반짝임 · ≈1.1 손바닥이 받아 내는 고리·잔광 · ~1.5 종료.

**검정/회색**: 방울 본체는 알파 블렌드(어두운 먹물 방울), 주변 빛은 옅은 청회색 림 글로우로 대체해 어두운 배경에서도 읽히게 함.

**보고 (클라이언트 미지원)**: 런타임 색 입력(tint) 이 없어 색마다 시스템을 복제했다(16 × 26 레이어, 스펙에서는 함수 하나 `inkLayers(colour)`로 16개를 생성). 클라이언트에 `colorInput`(예: 런타임 RGB 곱) 이 생기면 시스템 1개로 줄일 수 있다.


## REDO 2026-10-25 (시각 재제작, 계약 동일)
- 시스템 16개 id(`ink_<colour>`)·역할 attached·duration 0.85·loop false 동일, 손바닥 오프셋 동일. 16개 모두 같은 함수에서 만들어져 레이어·타이밍·텍스처가 같고 색(본색 / 밝은 빛 / 하이라이트 / 어두운 먹물)만 다르다. 텍스처는 흰·회색 중립(색은 colorOverLifetime).
- 2차(코디네이터 피드백 '너무 작고 짧음'): 몸 크기에서 읽히도록 키움 — 손끝에서 솟는 잉크 리본, 주먹 크기 공중 잉크 구슬, 서예 시길 고리, 어두운 먹물 튐+색 반짝임, 0.78 s 구슬이 터져 염료 방울이 손으로 떨어짐, 약 1.5 s까지 보임. 방출은 여전히 0.85 s 안(duration 0.85 그대로), 긴 수명 입자로 길이를 확보.
- client_compat fix 0건, check OK. 데모 `close`(손 근접) 추가.
