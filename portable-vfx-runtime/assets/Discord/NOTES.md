# Discord (마인드컨트롤) — 변환 메모 (REDO 2026-10-25)

**배치**: 세 시스템 모두 `role: attached`, **대상(조종당하는 몬스터)** 에 붙인다. anchor = 대상 발(바운딩박스 바닥 중앙), facing = 대상 몸 yaw. 대상이 움직이면 따라간다.
**크기**: 런타임 입력 `targetHeight` = 대상 바운딩박스 높이 → s = clamp(h/1.8, 0.5, 2.5). 표식은 1.8 m 기준 머리 위 약 0.42 m(2.22 m), 눈 잔광은 1.55 m·정면 0.25 m.

| 시스템 | phase | 모드가 할 일 |
|---|---|---|
| `discord_begin` | begin | 조종 적용 순간 재생 (보라 실이 위에서 꽂히고, 0.14 s에 땋은 가시 왕관+정신 시길이 머리 위에서 '탁' 맞물림(섬광·파동·불꽃·파편), 왕관에서 머리·어깨·양손으로 꼭두각시 실이 내려오고 0.16 s 눈이 자홍빛으로 켜짐) |
| `discord_mark` | sustain (0.55 s 부터) | 왕관·가시·룬 고리·시길이 머리 위에서 돌고, 팽팽한 실 5가닥을 따라 빛 맥동이 내려가며 눈 잔광 유지. 유지 레이어는 입자 1개씩(onStop 0.05 s). `holdDuration` = 실제 조종 남은 시간(기본 6 s) |
| `discord_end` | end | 유지 종료/해제(대상 사망·조기 해제 포함) 시 실이 끊겨 왕관 쪽으로 감기고 왕관이 부서지며 눈이 꺼짐, 0.6 s 내 소멸 |

- 런타임 입력: `targetHeight`, `holdDuration`(기본 6, 범위 0.05–60). 조기 해제 = sequence cancel → end 재생.
- 대상 사망/디스폰: 방출 중지 + local 레이어 정리(SCHEMA §5 attached).
- 외부 기능(이 파일 아님): 몬스터가 가까운 다른 몬스터를 공격하게 하는 AI 처리, 보스 제외, 마나 110 / 쿨타임 30 s, 획득 조건(스켈레톤 화살로 다른 몬스터가 스켈레톤 공격 10회).
- 참고(보고): 눈 위치는 1.8 m 인간형 기준 비율로 고정이다. 눈 높이가 다른 몹(거미·크리퍼 등)에서는 잔광이 얼굴과 어긋날 수 있다 — 대상별 눈 높이 입력은 스키마에 없다(headAttach 는 클라이언트 미지원). 필요하면 모드가 eye 높이 기준으로 anchor 를 보정하는 방안을 검토.
- 큰 연기·구체·바닥 마법진 없음. 실 끝점은 1.8 m 인간형 기준 고정점(손 (±0.37, 0.88), 어깨 (±0.24, 1.48), 머리 위 1.82)이며 팔 애니메이션은 따라가지 않는다(손 부착 입력 없음).
