# InvertedOffering (뒤집힌 공물) — converter notes

- 패시브 발동 VFX. 외부 게임 기능이 "드롭 → 제물 전환 성공" 이벤트를 낼 때마다 새 인스턴스 1개를 재생한다 (시전 대기 없음, 마나 0, 쿨타임 0).
- system `offering`, role `link` (SCHEMA §5): source = 제물 전환이 일어난 처치 위치(몹 발 위치, 세계 좌표), target = 시전자 발 위치 + (0, 1.1, 0) 가슴 높이. 매 프레임 target 갱신(이동 중인 시전자에게 빛이 따라감).
  모든 연출은 source 기준 0.4 m 위에서 모이며, source 를 몹 중심으로 줄 경우 레이어 position 은 그대로 둬도 된다(0.4 m 더 높아짐).
- 시간: 0~0.35 s 검남색 그림자 조각 6개 + 잉크 소용돌이가 안쪽으로 접히며 수축 → 0.26~0.3 s 연녹색 빛으로 전환 → 0.3~0.85 s 빛 4개가 시전자로 흘러듦 → 0.75~0.9 s 시전자 위치의 작은 빛. 전체 약 0.9 s.
- 인스턴스당 입자 최대 약 19개(+빛 4개의 짧은 트레일). 여러 번 겹쳐도 작게 유지되도록 설계. 렌더러가 동시 인스턴스를 줄여야 한다면 **시각 인스턴스만** 줄이고 게임 효과(경험치 지급 횟수)는 제한하지 않는다.
- 빛 입자 4개는 고정 연출이며 추가 경험치 양과 무관하다(변환 비율 미정). 빛 입자 수로 지급량을 표현/고정하지 않는다.
- VFX 는 아이템·경험치 구슬 엔티티를 만들지 않는다. 드롭 소모, 추가 경험치 지급, 등록 여부 판정, 퀘스트 보상 제외, 습득 조건(바닐라 레벨 30)은 모두 외부 게임 기능.
- 처치 위치와 시전자 거리가 멀어도 빛 수명은 0.46~0.54 s 고정(경로 진행 비율 기반)이라 먼 거리에선 빠르게 날아간다.
- 클라이언트 호환: 툴킷 내보내기가 기본값으로 쓰는 height/depth(null), orientation("world"), attachPoint/follow(null), lights([]), rollWithTravel(null) 키를 vfx.json 에서 제거함 — 값은 모두 기본값이라 동작 차이 없음. client_compat check OK.

## 2026-10-25 재제작 (시스템·역할·타이밍 그대로)
- 시스템 `offering` (link) 하나, 방출 0.55 s, 전체 약 0.9 s — 그대로. 현재 바인딩 그대로: trigger cast(시전 모습) + external:offering(전환된 처치마다), 16 t, source = event-point(처치 발 위치 / 조준점), target = caster(발), 매 프레임 갱신. 위 예전 메모의 "target +1.1 m 가슴"은 현재 바인딩(발)에 맞춰 도착 연출을 발밑 평면 링으로 바꿈.
- 시간: 0~0.28 s 바닥 잉크 웅덩이 위에서 공물 마법진(이중 삼각, 하나는 뒤집힘)이 0.4 m 떠오르며 천천히 뒤집히고, 룬띠가 돌고, 전리품의 그림자(잉크 초승달) 12개가 3단계로 빨려 들어오며, 잉크·보라 호가 안쪽으로 감기고, 잉크 핵이 생김 → **0.28 s 전환**: 옅은 빛 섬광, 선 파동(공중·바닥), 마법진 플레어, 모트·잉크 조각 → 0.3~0.76 s 옅은 경험의 빛 5개(트레일)와 실, 모트가 곡선으로 시전자에게 흘러감 → 0.74~0.9 s 발밑 흡수 링, 작은 원진, 글린트.
- 빛 5개는 고정 연출이고 지급량과는 관계없음. 거리와 상관없이 경로 진행 비율로 같은 시간에 도착. 겹쳐도 작게 유지됨(멀티 5회 미리보기).
