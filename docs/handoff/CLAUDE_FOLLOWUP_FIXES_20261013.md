## 3. 2차 수정 (2026-10-13 20시, 사용자 실게임 피드백)

버전은 MagicCodex `...-followup.2`, 모션 모드 `0.3.0-codex.3-hud.2`다. 타입 검사는 두 모드 모두 오류 0건이고, `FollowupFixesTest`와 `AimTest` 16개가 통과했다.

| 피드백 | 처리 |
|---|---|
| 바닥 전용 스킬(화염벽 등)이 공중에 지정됨 | 원인: Codex 통합판은 조준 레이가 빗나가면 공중의 사거리 끝점을 그대로 썼다. 서버(`SpellRuntime` AIM)도 빗나간 레이의 끝점을 쓰므로 공중 시전이 실제로 가능했다. 수정: `AimTargeting.grounded`(AREA·POINT·WALL)이 빗나가면 끝점 아래 바닥으로 내린다. 사거리를 넘거나 시야가 막히면 시전자 쪽으로 5%씩 당긴다. 그래도 없으면 "바닥을 조준해 주세요."로 막는다. 직선·부채꼴·대상 지정은 그대로다 |
| 화염벽 미리보기 양 끝이 툭 끊김 | `AimRenderer.wallHologram`: 레인 텍스처(가장자리 밝음)와 블룸으로 그린다. 양 끝은 반원 캡(`AimMath.capsuleEnd`)이고, 끝으로 갈수록 투명해진다 |
| 히트박스를 보고 있어도 교화 카드가 안 뜸 | 원인: 서버 교화 레이는 눈에서 머리 방향으로 쏜다. 어깨 시점의 조준점 레이는 카메라 위치에서 나와 평행하게 어긋나 있다. 수정: `CrosshairAim`이 조준점 아래 생물이 눈 레이에 안 걸릴 때만, 교화 조회 패킷과 교화 시전(`taming`, `rainbow_collar`) 직전에 그 생물을 향한 시선 패킷을 1회 보낸다. 직후 실제 시선으로 되돌리며, 프로토콜은 바꾸지 않았다 |
| 비행 HUD 검은 배경·"균형" 글씨 | 패널 배경과 모든 글씨를 제거했다("연습용 N초" 포함) |
| 비행 HUD 저화질 | 바닐라 GUI blit은 nearest 샘플링이라 큰 원본을 작게 그리면 깨진다. 모션 모드에 `HudArt`를 추가했다. 밉맵·트리리니어 텍스처, 실수 좌표 쿼드, Pretendard 화면 해상도 래스터 글씨로, MagicCodex HUD와 같은 방식이다. 텍스처는 `textures/gui/hud/`에 정리했다(정렬·잡티 제거·투명 가장자리 색 보정). 옛 `followup/flight_*`와 `flight_atlas.png`는 삭제했다 |
| 게이지가 갑자기 잘리며 줄어듦 | 균형 아치: 값이 지수 감쇠로 따라가고, 끝은 페더 처리했다. 급락하면 옅은 잔상이 0.35초 동안 따라 내려온다. 부스트 링: 아래에서 자르던 방식을 시계 방향 스윕으로 바꾸고 끝을 14° 페더 처리했다 |
