# 한국어 스토리 명령과 클라이언트 리로드 (2026-10-11)

## 기준과 보존
4014a51f1a4a4cc7cbf5791fdc64f5a9ffad94d2 기준. bdf0682 초상화 클리핑, Story client-only/고정 보상/닉네임 ACK와 최신 채팅·파티 변경을 유지했다. 기존 미커밋 변경은 별도 패치와 ZIP으로 보존한 뒤 충돌 없이 통합했다. 개인 폰트·콘텐츠·설정·JAR은 공개 소스에 넣지 않는다.

## 사용법
- 관리자: `/컷신 재생 <유저·한글닉> <id> [자동|건너뛰기허용|건너뛰기금지]`, `/스토리 재생 <유저·한글닉> <id>`. 각 루트에서 중지·취소·목록·리로드·서버리로드 지원.
- 내 클라이언트: `/스토리도구 재생|목록|리로드`, `/컷신도구 재생|목록|리로드`. 관리자 서버 루트를 가리지 않는다. 기존 `/story reload`도 같은 대화 검사 기능이다.
- 기존 영어 호출과 `/스토리대화` 호환 별칭 유지. 관리자 권한은 `chacademy.story.admin` 그대로.
- 정확한 한글 닉네임과 공백 닉네임은 Bridge의 기존 DisplayNames.resolve를 공개 facade로 연결해 재사용. 미발견/중복 닉네임은 실행하지 않고 영문 계정명을 안내한다.
- 리로드는 대화 종료·이벤트 commands를 포함해 파싱 검사하고 목록만 갱신한다. 현재 대화, 완료·호감도·보상 기록을 변경하지 않는다. 명령·보상 실행도 없다. 다음 재생은 기존처럼 파일을 새로 읽는다.
- 서버 관리자 리로드 결과는 대상 클라이언트 화면에 표시한다. 서버리로드는 기존 서버 설정·호환용 대화 정의 검사이며 별개다.
- 자동완성은 메모리만 읽는다. 접속/리로드 때 ID만 종류별 최대128개 전달한다. 내용·명령·경로·진행 기록은 보내지 않고 추천 목록을 권한·보상 근거로 사용하지 않는다. 서버 그래프 복사 필수 구조를 복원하지 않았다.
- 로컬 완료 기록 초기화 명령은 추가하지 않았다. 기존 서버 ledger/reset은 예전 서버 기록, 클라이언트 resetseen은 컷신 본 기록만 다룬다.

자세한 사용자 안내와 구형 호환 범위는 `chacademy-story/README.md`.

## 남은 실제 플레이 검증
당시 접속자 0명이므로 로그인 재연결, 한글닉/ID 자동완성 화면, 실제 대화 보상, 두 계정의 서버 이동·파티 채팅·백엔드 닉네임 패킷은 직접 검증하지 않았다. 포트와 기동 검사를 실제 플레이 검증으로 대신하지 않는다.
