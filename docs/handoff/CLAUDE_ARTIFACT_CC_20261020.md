- 감소는 곱해서 적용합니다. 예: 방패 배지 + 굳센 심장 = 0.85 × 0.5.
- 마법·원소 반응·몹 스킬 등 출처와 관계없이 상태이상 엔진으로 걸리는 모든 디버프에 적용됩니다. 마나번은 제외합니다(즉시 효과).
- 바닐라 포션 효과에는 적용되지 않습니다.
- "CC에 걸린 적"은 기절·수면·속박·공포·무장해제·둔화·중력·고정·실명 중 하나라도 걸린 상태입니다.
- 예전 효과(절지류 피해, 웅크림 피해, 고지대 피해, 해질녘 피해, 뇌우 피해, 폭발 피해 감소, 방패 내구도)는 삭제했습니다.

## 3. 코드

### MagicMythic (magic-mythic-paper)

- **새 이벤트 `MagicStatusEvent`:** `StatusEffects.apply`에서 대상이 플레이어일 때만 발생합니다(듣는 쪽이 있을 때만).
  - `setTicks` / `setCancelled`로 시간을 바꾸거나 막습니다. 마나번은 발생하지 않습니다.
- **`MagicReactionEvent`:**
  - 추가: `multiplyControl(double)`(0.25~3), `setNormalControlBonusTicks(int)`(0~60)
  - `isControl()`은 증기 폭발·무지개·섬광을 뺀 전부로 바꿨습니다.
- **`Reactions.cc`:** 시간 = 기본 × 배율 + 보너스 틱 + (일반 CC일 때) 일반 보너스 틱
  - 태양 플레어 발광도 같은 계산을 씁니다.
  - 모래 회오리는 스코어보드 태그 `chacademi_anchor`가 있는 대상을 끌지 않습니다(고정은 걸림).
- **공개 API `isControlled(LivingEntity)`:** 제압의 머리띠용입니다.

### MagicCodexBridge (magic-codex-paper)

- `ArtifactEffects.controlTaken`: 위 감소표입니다.
- `MagicStatusEvent` 연결은 따로 시도합니다. MagicMythic가 이전 버전이면 경고만 남기고 나머지 아티팩트 연결은 그대로 됩니다.
- 닻 장식: `apply()`에서 태그를 붙이고 떼며, 나갈 때 뗍니다.
- 굳센 심장 받는 피해 +10%는 `hurt()`에 넣었습니다.
- `ArtifactLife`: 방패 배지 내구도 줄을 지웠습니다.
