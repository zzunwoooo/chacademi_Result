# 상태 HUD 패치 수동 테스트 — 2026-10-19

실제 `plugin.yml`, `MagicMythicPlugin.onCommand`, `StatusCommand`, `StatusProtocol.Status`, `TargetHudClient` 등록 코드를 확인한 목록입니다. 아래는 사용자가 실행할 체크리스트이며, 자동으로 실게임 테스트를 수행했다는 뜻은 아닙니다.

## 준비

- 새 클라이언트로 다시 접속합니다. 이미 게임이 실행 중이었다면 모드 교체는 다음 게임 실행부터 적용됩니다.
- 서버 명령은 OP 또는 `chacademia.magicmythic.admin` 권한이 필요합니다. 권한 검사 자체를 끄지 않습니다.
- 상태이상 대상은 서바이벌로 준비합니다. 크리에이티브·관전자·면역 대상은 거부됩니다.
- 한 번에 하나씩 시험하고 `/마법미몹 상태이상 해제 나` 또는 `/마법미몹 상태이상 해제 바라봄`으로 정리합니다. 이것은 커스텀 상태이상만 제거합니다.
- 기존 원격 감독 콘솔에서 한글이 물음표로 전달되는 문제가 확인됐으므로 게임 채팅에서 실행하세요. `나`/`바라봄`은 플레이어 발신 명령입니다. 대상에는 정확한 접속 플레이어 이름도 쓸 수 있습니다.

## HUD와 표시

| 명령 또는 행동 | 기대 결과 |
|---|---|
| `/대상체력바미리보기 일반` | 일반 대상 가짜 체력 HUD, 15초 후 종료 |
| `/대상체력바미리보기 이로치` | 이로치 체력바 색상 |
| `/대상체력바미리보기 플레이어` | 플레이어 체력·마나 표시 |
| `/대상체력바미리보기 보스` | 보스 상단 + 작은 일반 몹 하단의 2단 HUD |
| `/대상체력바미리보기 끄기` | 미리보기 종료 |
| 상태 아이콘이 있을 때 채팅 또는 Ctrl 커서를 열고 마우스 올리기 | 이름·효과 설명·남은 시간. 머리 위 아이콘에는 팝업 없음 |
| 일반 몹을 바라보고, 때리고, 시선을 다른 몹으로 이동 | 전투 상대가 10초 우선. 전투 대상은 48블록, 바라보는 대상은 약 25블록 범위 |
| 기존 보스 64블록 안에서 일반 몹을 바라보기 | 보스가 상단 우선, 일반 몹이 두 번째 바. 바닐라와 플러그인 보스바는 모두 숨김 |
| 자기 MCPets 펫 / 다른 플레이어 바라보기 | 자기 펫은 제외, 다른 플레이어는 표시 |
| 큐디치 경기에서 HUD 확인 | 점수판 아래로 대상 HUD 배치. 기존 플러그인 보스바는 의도적으로 숨겨짐 |
| `/effect give @s minecraft:slowness 5 0 true` | 바닐라 둔화가 커스텀 둔화 아이콘으로 표시. 바닐라 효과 HUD는 숨김. 인벤토리 효과 목록은 유지 |

## 상태이상 16종

`/마법미몹 상태이상 목록`으로 서버가 인식하는 전체 이름을 확인합니다. 기본 형식은 `/마법미몹 상태이상 <종류> <초> <나|바라봄|플레이어이름> [세기]`입니다. 숫자는 현재 코드 기본 설정 기준입니다.

| 상태 | 실행 명령 | 확인할 동작 |
|---|---|---|
| 기절 | `/마법미몹 상태이상 기절 3 나` | 이동·점프·근접·활·일반 마법·아티팩트 차단 |
| 수면 | `/마법미몹 상태이상 수면 5 바라봄` | 일반 몹 정지. 피해를 받으면 깨어남 |
| 속박 | `/마법미몹 상태이상 속박 3 나` | 이동·점프 차단, 공격·마법은 허용 |
| 무장해제 | `/마법미몹 상태이상 무장해제 3 나` | 근접·활·일반 마법 차단. 아티팩트는 허용 |
| 둔화 | `/마법미몹 상태이상 둔화 5 나 0.5` | 이동 속도 50% 감소 |
| 화상 | `/마법미몹 상태이상 화상 5 바라봄` | 몸에 불이 붙지 않음. 지속 중 가한 피해 합의 기본 10%가 종료 시 추가 피해. 미리 해제하면 추가 피해 없음 |
| 회복봉인 | `/마법미몹 상태이상 회복봉인 5 나` | 체력 회복·마나 자연 회복·마나 회복 아이템 제한 |
| 약화 | `/마법미몹 상태이상 약화 5 나` | 같은 마법 피해가 기본 30% 감소 |
| 중력 | `/마법미몹 상태이상 중력 3 나` | 비행 중 빗자루 하차·겉날개 비행 중지·비행 마법 제한 |
| 고정 | `/마법미몹 상태이상 고정 5 나` | 이동 마법 제한. 상태를 건 뒤 새 빗자루 탑승 시 하차 |
| 독 | `/마법미몹 상태이상 독 5 나` | 기본 초당 1 피해, 체력 1 아래로는 내려가지 않음 |
| 나약함 | `/마법미몹 상태이상 나약함 5 나` | 같은 일반 근접·활 등 비마법 피해가 기본 30% 감소 |
| 실명 | `/마법미몹 상태이상 실명 3 나` | 실명 시야와 커스텀 아이콘 |
| 물약봉인 | `/마법미몹 상태이상 물약봉인 5 나` | 물약 마시기·던지기와 마나 물약 제한 |
| 마나번 | `/마법미몹 상태이상 마나번 5 나` | 즉시 최대 마나의 기본 10% 소모. 아이콘 중 재실행해도 다시 소모되지 않음 |
| 공포 | `/마법미몹 상태이상 공포 5 바라봄` | 일반 몹이 시전자에게서 도망가며 공격하지 않음 |

보스에게 기절·수면·공포는 기본 45% 둔화로 바뀌고 속박은 거부됩니다. 화염의 정복자 패시브가 적용된 플레이어는 화상 자체가 거부됩니다.

## 실제 스킬 연동

일반 전투 가능한 대상과 장소에서 실행합니다. 시험 명령은 **마나·쿨타임·일반 시전 경로·VFX 카탈로그를 우회**하므로 상태이상에 의한 시전 차단 테스트에는 일반 장착 마법을 사용하세요.

| 명령 | 기대 결과 |
|---|---|
| `/마법미몹 시험 pressure_hammer` | 수압해머 적중 시 약 1초 기절. 보스는 둔화 |
| `/마법미몹 시험 abyssal_pressure` | 심해의 압력 지대에서 둔화·나약함. 예전 채굴 피로 대신 새 나약함 |
| `/마법미몹 시험 pressure_press` | 윈드 프레스 적중 시 약 2초 중력 |
| `/마법미몹 상태` | 현재 진행 효과와 상태이상 개체 수 표시 |

시험 명령이 `대상이 필요합니다`라고 응답하면 사거리 안의 전투 대상을 바라보고 다시 실행합니다. 상태이상을 적용한 뒤 해제하고, 아이콘 소멸 및 이동·회복·시전 복구까지 확인하세요.
