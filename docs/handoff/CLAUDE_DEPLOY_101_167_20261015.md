3. **클라이언트 (런처, 준우 님 런처 포함)**
   - MagicCodex 클라이언트 JAR: default-spells 101~167 최신(설명·조건·연구기록·마나·쿨, `cast.command: 마법 <id>` 63개).

4. **도감 폴더 자동 갱신 (MagicCodex 코드 — GPT 검토 요청)**
