## 1. What the owner asked for

- **Caught fish go into the 통발 tank, not the inventory.**
  - Each fish is its own DB row (id, species, size, caught date).
  - Capacity is 100 (`fishing.yml tank.capacity`). A full tank blocks fishing.
  - Treasure chests still go to the inventory, or to mail when it is full.
- **Tank, locks and prices are shared by school and wild through the player-state MariaDB.**
  - `codex_fish_tank` and `codex_fish_lock`.
  - Prices: `fish-shop.yml` through the `SharedConfigText` row `fish_shop` in `codex_shared_config`.
  - Without a shared DB it falls back to a per-server `fishing.db`.
- **물고기 판매소** (its own shop, not ShopStore), refs `textures/gui/fish_shop`:
  - 판매 tab: sells every fish of the checked grades.
  - 잠금 설정 tab: locked species are never sold, whatever the size.
  - Prices: grade base 80 / 400 / 2000 / 10000, ×1.3 for fish with special conditions, per-fish overrides, and a size factor from ×0.7 to ×1.5. They can be changed live with `/물고기상점관리 가격|크기보정|조건보정|리로드`.
  - NPC and portrait work like the normal shop: `/물고기상점관리 NPC citizens:<id>` and `초상 <id>`. The NPC list stays per server in `fish-shop-npcs.yml`.
- **통발 tank window** (fullscreen, refs + art in `textures/gui/fish_tank`):
  - Fish swim freely.
  - Sunlight from above: the rays sway and flicker, and two caustic layers move over the sand and under the surface.
  - Clicking a fish zooms in smoothly (eased progress + smoothed focus, about 380px). The background edge blurs through a radial mask (a pre-blurred copy under the sharp one).
  - Info panel: name, grade, size, caught date, sale price, 개체 번호, description, and three buttons:
    - **아이템화**: refused when the inventory is full.
    - **방생**: press twice. Only the DB row is deleted; the codex record stays.
    - **즉시 판매**: refused for locked species.
  - Right list: search, 최근 / 등급 / 크기, and **넣기**. 넣기 lists the fish items in the inventory; clicking one opens a popup with 수조에 넣기. The owner asked for no inventory band at the bottom.
- **통발 is one spell**: `fish_trap`, order 324.

## 2. Safety (decided on the server, against the DB)

- **Taking out, releasing and selling** delete the row first (`DELETE … WHERE id=? AND uuid=?`). Only a row that was really deleted gives an item or money, so a double click or the other server can never pay twice. A sale whose payment fails puts the same fish back with the same id.
- **Itemized fish keep their tank id and caught date** in the item PDC (`fishing_tank_id`, `fishing_caught`).
  - Putting one back takes the item first, then inserts it with that id (the primary key).
  - A duplicated item is refused and stays consumed (log `FISH TANK duplicate item refused`).
  - A database error or a full tank gives the item back.
  - Old fish items without an id get a new one.
  - Admin `물고기지급` items also get an id.
- **Itemized fish are not sellable at the shop**, because the shop only sells from the tank.
- **Locked species are never sold**: not by grade sale and not by instant sale.

## 4. Deploying (GPT)

1. Build and run the tests. Claude only checked compiling against the API sources and stubs, plus the protocol round trips. This is not a Gradle build.
2. **Live config is not overwritten by the jar.** Merge these by hand:
   - Add the `fish_trap` entry to the live `plugins/MagicCodexBridge/mana-spells.yml` on school and wild.
   - `fishing.yml` needs `tank: { capacity: 100 }`. The default is 100 if it is missing.
   - `fish-shop.yml` and `fish-shop-npcs.yml` are created on first start.
3. `fish_trap` has **no PortableVFX catalog entry**. Its cast goes through `ManaBridge` straight to the window, without `runtimeCast` or the catalog check, like `wind_message` without a visual. If the codex or the deploy guard insists on a catalog entry, add one with `enabled: false`, or report it to Claude.
4. Shop NPC: `/물고기상점관리 NPC citizens:<id>` and `/물고기상점관리 초상 <portrait>` on each server.
5. **Quick checks:**
   - Catch a fish: it goes to the tank, with the `n/100` note.
   - Fill the tank to 100: casting is blocked.
   - `/마법 fish_trap` or the codex key opens the window.
   - Click a fish: zoom, blur and panel appear.
   - 아이템화 with a full inventory is refused. With room, the item appears and the row is gone. Putting it back from 넣기 works. A /give copy of the same item is refused.
   - Release takes two presses.
   - Instant sale of a locked species is refused. An unlocked one pays.
   - Shop grade sale skips locked species and itemized fish.
   - Changing a price on school shows on wild within about 5 seconds.
