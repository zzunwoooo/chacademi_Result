## NPC 명령

```
/NPC관리 명찰 설정 근처 엘레나 학생지도교수
/NPC관리 명찰 설정 근처 "엘레나 교수" "학생 지도 교수"
/NPC관리 명찰 칭호 근처 앞 소환술
/NPC관리 명찰 칭호 근처 뒤 교수
/NPC관리 명찰 칭호 근처 앞 비우기
/NPC관리 명찰 칭호 근처 뒤 비우기
/NPC관리 명찰 칭호 근처 초기화
/NPC관리 명찰 조회 근처
/NPC관리 명찰 초기화 근처
```

`설정`의 단일 칭호는 접두를 비우고 접미에 저장한다. 앞/뒤는 자유 문구이며 무공백으로 결합한다. 이름과 각 문구는 48 유니코드 코드포인트 이하, 제어/서식 문자 금지. 공백은 따옴표로 입력한다. `""`로 빈 문구도 가능하다. 문구 자동완성에 칭호 카탈로그를 제안하지 않으며 비우기·대상 자동완성은 유지한다. 대상은 기존처럼 근처 또는 이름/닉네임/안정 ID이며 관리자 권한·24블록 제한·중복 대상 오류는 유지한다.

NPC 색은 기존 suffix 기본색 `#DEC58E`이다. 플레이어는 기존 소유·장착 데이터를 유지하며 suffix가 있으면 접두+접미 모두 해당 suffix 색, prefix만 있으면 그 prefix 색이다. 채팅·다른 UI·칭호 카탈로그·지급/보유 데이터는 변경하지 않는다.

저장 버전 3은 `prefix-text`/`suffix-text`를 추가한다. 기존 `prefix-id`/`suffix-id`는 카탈로그로 정상 해결되는 경우 표시 이름으로 읽고, 해당 NPC 수정 시 문구로 고정해 저장한다. 미해결/잘못된 슬롯 ID는 데이터로 보존하고 명찰에는 출력하지 않으며 조회에서 알려 준다. ID를 문구로 추측하지 않는다. 기존 자유 직책 데이터도 카탈로그 ID와 혼동하지 않는다. ChacaNPC 안정 캐릭터 ID → Citizens UUID → 엔티티 영속 PDC 식별 순서는 유지한다.

## 자기 명찰

서버는 본인의 기숙사·순수 이름·장착 칭호도 기존 권위 스냅샷에 넣는다. 일반 상태에서는 클라이언트가 숨긴다. 기존 `HudCursorScreen` 활성 동안만 표시하므로 현재 마우스 포인터 키(기본 Ctrl)의 누르고 유지/해제 동작과 리매핑을 그대로 따른다. 별도 raw Ctrl 검사는 추가하지 않았다. 채팅/인벤토리/다른 GUI, HUD 숨김, 사망/관전자/보이지 않음에는 자기 표시를 하지 않는다.
