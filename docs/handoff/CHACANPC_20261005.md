### 선물 처리 순서

1. 같은 플레이어의 선물은 한 번에 1건만, 클릭 간격 400ms
2. Bridge에 하루 횟수 예약 + `pending` 기록 (같은 토큰은 한 번만)
3. 같은 칸에 같은 아이템이 그대로 있을 때만 1개 차감. 바뀌었으면 취소하고 횟수를 돌려줌
4. 확정
5. 확정이 실패하면 취소가 확실히 성공했을 때만 아이템을 돌려줌. 취소도 실패하면 pending으로 남고 다음 시작 때 "아이템 차감됨"으로 확정됨 (환불과 점수 중복 없음)
6. 차감 뒤 확정 전에 서버가 꺼진 경우도 다음 시작 때 같은 방식으로 확정됨 (`recover-pending-gift-minutes`)

## 3. 고정 대화에서 쓰는 방법 (Bridge)

| 종류 | 형식 | 의미 |
| --- | --- | --- |
| 조건 | `custom affinity ella>=20` / `custom affinity ella heart<1` | 점수·하트 단계 분기 |
| 동작 | `custom heart ella 1` | 하트 이벤트 1 완료. 점수 상한 해제, ChacaNPC에 사건 → 소문 |
| 동작 | `custom affinity ella +5` | 호감도 변화 (출처 dialogue) |
| 동작 | `custom nickname ella 책벌레` | 호칭 이벤트 |

점수 상한은 하트 단계 h일 때 20×(h+1)점입니다(4 이상이면 100). 하루 한도는 `affinity.yml`에 있습니다.
