# 운빨깨굴랜드 운영 명령어 안내

모두 OP(운영자)만 쓸 수 있어요. 닉네임 칸에는 한글 닉네임을 그대로 쓰면 돼요.

## 칭호 주기 / 빼기

```
/깨굴 칭호 <닉네임> 주기 <칭호id>
/깨굴 칭호 <닉네임> 빼기 <칭호id>
```

- 칭호 id 는 자동완성으로 나와요. 지금 있는 것: `luky`, `lucky_guy`, `amazing`, `jail_home`, `jail_server`, `host_noob`(허접섭주), `staff_slave`(운영노예), `donation_king`(기부왕)
- 예: 기부왕 주기 → `/깨굴 칭호 <닉네임> 주기 donation_king`
- **새 칭호 만들기:** `plugins/KkaegulCore/config.yml` 의 `titles.list` 아래에 한 줄 추가하고 `/깨굴 리로드`

```yaml
    vip: { name: "&b[VIP]", description: "운영자가 준 칭호" }
```

  - 조건을 넣으면 자동으로 받아요: `condition: "jail >= 50"` (jail·breaks·deaths·increased·submitted·donated·graduated), `gacha-roll: 7` (가챠 7/7/7)
  - `fortune-bonus: 1` 을 넣으면 행운 +1
- 유저는 `/칭호` 로 가진 칭호를 보고 고를 수 있어요.

## NPC 만들기 (Citizens)

### 자주 쓰는 Citizens 명령어

```
/npc create <이름>        ← 내가 선 자리에 NPC 생성 (바라보는 방향 그대로, 만든 NPC 가 '선택'됨)
/npc select               ← 바라보는 NPC 선택 (또는 NPC 를 막대기로 우클릭)
/npc remove               ← 선택한 NPC 삭제
/npc rename <이름>        ← 이름 바꾸기 (&색코드 가능)
/npc skin <마크 계정 이름> ← 그 사람 스킨 입히기
/npc type <몹종류>        ← 사람 대신 몹 모양 (예: VILLAGER, FROG)
/npc tphere               ← 선택한 NPC 를 내 자리로
/npc moveto <x> <y> <z>   ← 좌표로 옮기기
/npc look                 ← 다가오는 사람을 쳐다보게 (켜기/끄기)
/npc name                 ← 머리 위 이름 숨기기/보이기
/npc equip                ← 장비 입히기 창 (손에 든 것 등)
/npc list                 ← NPC 목록과 번호
```

### NPC 에 기능 붙이기

1. `/npc create 상점` 처럼 NPC 를 만들어요.
2. NPC 를 6칸 안에서 바라보고 `/깨굴 npc 연결 <동작>` — 우클릭하면 그 기능이 열려요.
3. 서버를 껐다 켠 뒤 연결이 풀리면, NPC 를 선택하고 아래처럼 넣어요 (이 방법은 안 풀림).

```
/npc command add kg npc run <동작> <p>
```

- 연결 끊기: NPC 를 바라보고 `/깨굴 npc 해제` (Citizens 쪽은 `/npc command remove <번호>`, 번호는 `/npc command`)
- 동작 전체 목록: `/깨굴 npc` (자동완성에도 나와요)

| 동작 | 열리는 것 |
|---|---|
| `shop` | 상점 (코인 구매) |
| `sell` | 상점 판매 탭 |
| `gacha-1` · `gacha-2` · `gacha-3` | 곡괭이 가챠 1·2·3번 기계 |
| `frog-race` | 개구리 경주 배팅 |
| `frog-jump` | 개구리 점프 |
| `omok` | 오목 자유 대전 안내 (`/오목 신청`) |
| `wardrobe` | 옷장 (치장품) |
| `mail` | 우편함 |
| `playtime` | 접속 보상 |
| `hall` | 명예의 전당 (랭킹) |
| `titles` | 칭호 |
| `fortune` | 오늘의 운세 |
| `trash` | 쓰레기통 |
| `submit` | 다이아 제출 |
| `farm` | 농사 시세 |
| `wild` · `wild-random` | 야생 이동 · 야생 랜덤 이동 |
| `lobby` · `village` | 로비 · 마을로 이동 |
| `jail-game` | 감옥 돌림판 |
| `jail-exit-lobby` · `jail-exit-return` | 감옥 출구 (로비로 · 원래 자리로) |

## 151515 졸업자 동상 세우기

가챠 15/15/15 를 서버 최초로 달성하면 `[님 개쩔어요]` 칭호를 받아요. 동상은 Citizens NPC 로 세워요.

1. 동상을 세울 자리에 서서 바라볼 방향을 봐요.
2. `/npc create <닉네임>` — 그 자리에 NPC 가 생겨요 (머리 위 이름 = 닉네임)
3. `/npc skin <그 사람 마크 계정 이름>` — 그 사람 스킨을 입혀요
4. `/npc look` — 다가오는 사람을 쳐다보게 (선택)
5. 장비를 들게 하려면 손에 들고 `/npc equip`

이름 앞에 칭호를 붙이고 싶으면 2번에서 `/npc create &d[님 개쩔어요] &f<닉네임>` 처럼 써요.

## 쿠폰

```
/쿠폰관리 만들기 <이름>   ← 상자 창이 열리면 보상 아이템을 넣고 닫기 = 저장
/쿠폰관리 편집 <이름>
/쿠폰관리 목록
/쿠폰관리 삭제 <이름>
```

유저는 `/쿠폰 <이름>` (한 사람당 한 번, 보상은 우편함으로)

## 오목 자유 대전 (유저용)

```
/오목 신청 <닉네임> <다이아>   ← 상대에게 대전 신청 (60초)
/오목 수락   /오목 거절
```

- 건 다이아는 시작할 때 둘 다 맡겨 두고, 이긴 사람이 상대 다이아를 가져가요. 수수료는 양쪽에서 5%씩 (`minigame.games.omok.duel.fee-percent`).

## 집 위치 (유저용)

- 내 땅 안에서 원하는 자리에 서서 땅 관리 창의 **여기를 집으로** 버튼 (또는 `/집설정`)
- 메뉴 이동 > 마을 을 누르면 그 자리로 와요. 안 정하면 땅 한가운데로.

## 이동

```
/텔포 <닉네임>   ← 그 사람에게 이동
/소환 <닉네임>   ← 그 사람을 내 위치로
```

## 감옥 돌림판 NPC

감옥 안 NPC 를 우클릭으로 고른 뒤 `/깨굴 npc 연결 jail-game`.
누르면 기본값 10~100 × 배수(꽝·0.2·0.5·1·2·3·5·10)만큼 남은 다이아가 늘어나요. 30초 쿨타임, 감옥 안에서만.
확률은 config `jail.game.multipliers` (x0_2 = ×0.2).

## 그 밖에

- 개구리 경주 멈춤/재개: `/깨굴 경주 멈춤`, `/깨굴 경주 재개`
- 괴롭히기 확률 보기: `/깨굴 괴롭히기 확률`
- 설정만 바꿨을 때: `/깨굴 리로드`
- 설정 파일: 호스팅 `이깨굴\plugins\KkaegulCore\config.yml` (메모장으로 숫자만 바꾸고 저장 → `/깨굴 리로드`. 칸 띄우기·따옴표가 틀어지면 못 읽으니 고치기 전에 복사본을 만들어 두기)
