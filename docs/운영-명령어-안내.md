# 운빨깨굴랜드 운영 명령어 안내

모두 OP(운영자)만 쓸 수 있어요. 닉네임 칸에는 한글 닉네임을 그대로 쓰면 돼요.

## 칭호 주기 / 빼기

```
/깨굴 칭호 <닉네임> 주기 <칭호id>
/깨굴 칭호 <닉네임> 빼기 <칭호id>
```

- 칭호 id 는 자동완성으로 나와요. 지금 있는 것: `luky`, `lucky_guy`, `amazing`, `jail_home`, `jail_server`
- **새 칭호 만들기:** `plugins/KkaegulCore/config.yml` 의 `titles.list` 아래에 한 줄 추가하고 `/깨굴 리로드`

```yaml
    vip: { name: "&b[VIP]", description: "운영자가 준 칭호" }
```

  - 조건을 넣으면 자동으로 받아요: `condition: "jail >= 50"` (jail·breaks·deaths·increased·submitted·donated·graduated), `gacha-roll: 7` (가챠 7/7/7)
  - `fortune-bonus: 1` 을 넣으면 행운 +1
- 유저는 `/칭호` 로 가진 칭호를 보고 고를 수 있어요.

## 151515 졸업자 동상 세우기

가챠 15/15/15 를 서버 최초로 달성하면 `[님 개쩔어요]` 칭호를 받아요. 동상은 Citizens NPC 로 세워요.

1. 동상을 세울 자리에 서서 바라볼 방향을 봐요.
2. `/npc create <닉네임>` — 그 자리에 NPC 가 생겨요 (머리 위 이름 = 닉네임)
3. `/npc skin <그 사람 마크 계정 이름>` — 그 사람 스킨을 입혀요
4. `/npc look` — 다가오는 사람을 쳐다보게 (선택)
5. 장비를 들게 하려면 손에 들고 `/npc equip`

이름 앞에 칭호를 붙이고 싶으면 2번에서 `/npc create &d[님 개쩔어요] &f<닉네임>` 처럼 써요.

## 쿠폰

```
/쿠폰관리 만들기 <이름>   ← 상자 창이 열리면 보상 아이템을 넣고 닫기 = 저장
/쿠폰관리 편집 <이름>
/쿠폰관리 목록
/쿠폰관리 삭제 <이름>
```

유저는 `/쿠폰 <이름>` (한 사람당 한 번, 보상은 우편함으로)

## 이동

```
/텔포 <닉네임>   ← 그 사람에게 이동
/소환 <닉네임>   ← 그 사람을 내 위치로
```

## 감옥 돌림판 NPC

감옥 안 NPC 를 우클릭으로 고른 뒤 `/깨굴 npc 연결 jail-game`.
누르면 기본값 10~100 × 배수(꽝·0.2·0.5·1·2·3·5·10)만큼 남은 다이아가 늘어나요. 30초 쿨타임, 감옥 안에서만.
확률은 config `jail.game.multipliers` (x0_2 = ×0.2).

## 그 밖에

- 개구리 경주 멈춤/재개: `/깨굴 경주 멈춤`, `/깨굴 경주 재개`
- 괴롭히기 확률 보기: `/깨굴 괴롭히기 확률`
- 설정만 바꿨을 때: `/깨굴 리로드`
