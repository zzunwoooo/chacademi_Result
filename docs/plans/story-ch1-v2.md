## 큰 흐름

시작의 섬(**tutorial** 서버, 첫 접속) → 선착장에서 배 출항 (배 컷신) → **school** 서버 항구 마을 → 피피 상점 → 돈이 없어 어부 올레에게 → 낚싯대 → 1마리 낚기 → 올레에게 보여 주면 길잡이 별 → 셀마에게 팔기 → 피피에게 돌아가기(여비 마련, 매입 안내) → 광장 동상 → 학교 정문(루카·그레고르) 입학 → 분류의 거울 기숙사 → 로웰 사감(내 방·웨이포인트) → 연금실 앞 웨이포인트 등록 + 지도(J) → 베르나(연금술) → 엘레나 첫 수업 → 대도서관 이솔데 → 이론서 3권(책장 블록) → 잿빛 밤 동화 컷신 → 1장 엔딩.

- 오픈 첫날은 1장만 (config.yml `chapter-release open-through: 1`, 2장 잠금 그대로).
- 1장에 농사 없음. 연금실 창 열기·1장 보상은 보류 (명령 없음).
- **대화 ID = 단계 ID** — 예전 운영 초안이 ch1-14 에서 대화 ch1-12 를 다시 쓰던 것(올레 장면과 피피 준비 완료가 같은 ID → 두 번째는 "이미 본 대화"라 안 열림) 고침.

### 서버 (새 단계 키 `서버:` · `서버이동:`)

- 스토리 플러그인에 단계별 `서버:` 를 넣음 (Java, `QuestDefs`·`QuestEngine`). 그 서버의 `config.yml quest-server-id` 와 같을 때만 그 단계의 호출·시작명령·대기대화·목표 표시(포탈·징표·길잡이 별)를 함. 튜토리얼·학교 둘 다 세계 이름이 `world` 라, 이게 없으면 튜토리얼 좌표 포탈이 학교에 생기거나 피피 11번이 엉뚱한 서버 NPC 로 잡힐 수 있음.
- `서버이동: true` (ch1-8 만): 다른 서버에서 이 단계에 들어오면 Velocity(BungeeCord 호환 채널 `Connect`)로 그 서버에 보냄. 배 컷신(ch1-7)이 튜토리얼에서 끝나 ch1-8 로 넘어가는 순간 school 로 이동. 튜토리얼에 다시 접속해도 3초 뒤 다시 보냄. 학교에 도착하면 ch1-8 시작명령으로 항구 warp, 브람 대사.
- **전제 (A안, 진행 중인 별도 작업)**: 스토리 진행 기록이 두 서버가 같이 쓰는 공유 DB 여야 함. 지금 코드(`QuestProgress`)는 아직 서버마다 로컬 파일 → 공유 DB 작업이 들어가기 전에는 학교에 가면 진행이 이어지지 않음.
