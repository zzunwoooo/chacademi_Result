# 운빨깨굴랜드 UI 최종 목록 (10개)

UI를 줄이는 원칙: **버튼이 없거나 고를 게 1~2개뿐인 화면은 만들지 않는다.**
나머지는 중앙 멘트, 토스트, NPC 여러 개, 월드 전광판, 채팅으로 대체한다 (코드에 이미 반영).

## 만들 UI

| # | UI | 종류 | 프롬프트 | 비고 |
| --- | --- | --- | --- | --- |
| 1 | 왼쪽 HUD (운빨 게이지·남은 다이아·코인·피버·뱃지) | 상시 | 완료 | 감옥 운동 횟수도 여기 뱃지로 |
| 2 | 중앙 멘트 배너 + 토스트 | 상시 | 완료 | 거탐 퀴즈, WASD, 운세, 갑옷 뽑기, 제출 결과 등 전부 이걸로 |
| 3 | 다이아 증감 룰렛 (숫자 슬롯머신) | 연출 | 완료 | |
| 4 | 초대장 (봉투 → 카드 → 거부 불가 도장) | 연출 | 완료 | |
| 5 | 가챠 결과 (3칸 슬롯·잭팟·파괴·방지권) | 연출 | 완료 | 9번 기계 화면 안에서 굴러감 |
| 6 | 상자 오픈 (일반·고급·행운 + 전체 이벤트 배너) | 연출 | 완료 | |
| 7 | 피버 시작 (다이아·3배·상자) | 연출 | 완료 | |
| 8 | 가챠 기계 화면 | 창 | 완료 | 돌리기 버튼 |
| 9 | 메뉴 창 (탭 4개: 내 정보 / 접속 보상 / 칭호 / 명예의 전당) | 창 | **아래** | 접속 보상은 기획서에 "기능창"으로 명시됨 |
| 10 | 유저 선택 창 (유저 텔포권) | 창 | **아래** | 접속자 목록에서 고르기 |

## 없앤 화면 → 대체 방법 (코드 반영 완료)

| 없앤 화면 | 대체 |
| --- | --- |
| 제출소 | 일반 제출 NPC / 랜덤 제출 NPC 따로 (의뢰인 기획도 NPC 분리) |
| 기부 랭킹판 | 제출소 옆 월드 전광판 `/kg setloc board.donation` |
| 명예의 전당 공간 | 로비 월드 전광판 `board.increased`, `board.breaks`, `board.deaths`, `board.remaining` 등 (+ 메뉴 탭) |
| 작물 시세 | 월드 전광판 `board.farm` |
| 감옥 화면 / 출구 선택 | HUD 감옥 뱃지 + 출구 NPC 2개 (`jail-exit-lobby`, `jail-exit-return`) |
| 프로필 | NPC 누르면 채팅으로 이름 입력 |
| 갑옷 뽑기·운세·제출 결과 | 중앙 멘트 |
| 코인 상점 | NPC 클릭 = 1개, 웅크리고 클릭 = 10개 |
| 게이지 변동권 | 우클릭 = +10, 웅크리고 우클릭 = -10 |
| 우편함 | NPC/명령어로 한 번에 받기 |
| WASD·거탐 퀴즈·미니게임 진행 | 중앙 멘트 + 토스트 (퀴즈맵 보기는 문 위 글자) |

렌더러가 그리는 화면 목록은 config `ui.renderer-screens` 로 관리한다. 여기 없는 화면은 서버가 알아서 대체 출력한다.

## 9. 메뉴 창 프롬프트

```
마인크래프트 서버에서 쓸 게임 UI 에셋을 만들어줘. 앞서 만든 HUD, 중앙 멘트 배너, 룰렛, 초대장, 가챠, 상자, 피버와 같은 스타일 세트야.

[서버 컨셉]
"깨굴이의 위험한 초대 : 운빨깨굴랜드"라는 마인크래프트 운빨 서버야. 마스코트는 개구리 '깨굴이'. 플레이어가 키를 누르면 열리는 개인 메뉴 창이야. 내 기록을 보고, 접속 보상을 받고, 칭호를 고르고, 서버 랭킹을 보는 곳.

[만들 것: 메뉴 창 (화면 가운데 큰 창)]
1. 창 프레임: 가로로 넓은 크림색 창, 초록 테두리. 창 위쪽 가운데에 깨굴이가 매달려 있는 장식
2. 왼쪽 세로 탭 4개 (각각 보통 / 선택됨 상태)
   - 내 정보 (깨굴이 얼굴 아이콘), 접속 보상 (시계), 칭호 (리본 메달), 명예의 전당 (트로피)
3. 내 정보 탭용: 통계 한 줄 칸 (왼쪽 아이콘 자리 + 오른쪽 숫자 빈 칸), 아이콘 6종 — 다이아, 제출(상자에 다이아), 기부(하트), 깜빵(쇠창살), 곡괭이 파괴(부러진 곡괭이), 즉사(해골)
4. 접속 보상 탭용
   - 가로 진행 바 (빈 틀 + 채움), 위에 30분·3시간·8시간 눈금 마커 3개
   - 보상 카드 3상태: 잠김(회색 자물쇠) / 받기 가능(반짝이는 초록 테두리) / 받음(체크 도장)
   - 받기 버튼 (보통/눌림/비활성), 꽝 종이 교환 버튼
   - 수선 마법책 아이콘, 꽝 종이 아이콘
5. 칭호 탭용: 칭호 한 줄 칸 3상태 — 보유 / 선택 중(초록 체크) / 미보유(회색 + 자물쇠)
6. 명예의 전당 탭용
   - 랭킹 한 줄 칸 (순위 빈 칸 + 이름 빈 칸 + 수치 빈 칸)
   - 1·2·3등 메달 3종 (금·은·동)
   - 위쪽 작은 하위 탭 버튼 (보통/선택됨)
7. 닫기 버튼 (작은 X, 보통/눌림)

[스타일]
- 깔끔한 플랫 + 살짝 입체감 있는 캐주얼 게임 UI. 마인크래프트와 어울리게 모서리는 살짝 각진 둥근 사각형
- 개구리 초록 + 크림색 기반, 포인트는 다이아 하늘색과 코인 노랑만
- 외곽선은 굵고 단순하게, 그림자는 한 겹만
- 노이즈, 질감, 잔무늬, 반짝이 파티클, 과한 그라데이션 같은 자글자글한 디테일 전부 빼줘
- 면은 단색이나 아주 부드러운 2단 그라데이션까지만
- AI 그림 특유의 과한 광택, 뭉개진 장식, 의미 없는 문양 금지

[중요]
- 글자와 숫자는 절대 넣지 마. 모든 글자·숫자 칸은 빈 공간으로 (게임에서 직접 씀)
- 배경은 투명 또는 단색 회색 단일 배경
- 모든 부품을 상태별로 겹치지 않게 간격 넉넉히 한 시트에 배치, 정면 시점, 원근 없음
- 한 줄 칸과 진행 바는 가로로 늘려도 깨지지 않게 왼쪽 끝 / 가운데 / 오른쪽 끝이 구분되는 단순한 구조로
```

## 10. 유저 선택 창 프롬프트

```
마인크래프트 서버에서 쓸 게임 UI 에셋을 만들어줘. 앞서 만든 메뉴 창과 같은 스타일 세트야.

[서버 컨셉]
"깨굴이의 위험한 초대 : 운빨깨굴랜드"라는 마인크래프트 운빨 서버야. 마스코트는 개구리 '깨굴이'. '유저 텔포권'을 쓰면 접속 중인 사람 목록이 뜨고, 한 명을 고르면 그 사람 옆으로 순간이동해. 남의 방송에 쳐들어가는 장난용 아이템이야.

[만들 것: 유저 선택 창 (화면 가운데 작은 창)]
1. 창 프레임: 세로로 긴 크림색 창, 하늘색 테두리. 위쪽에 제목 빈 칸, 왼쪽 위에 텔포권 티켓 아이콘
2. 유저 한 줄 칸 3상태: 보통 / 마우스 올림(하늘색 강조) / 눌림
   - 왼쪽에 마크 얼굴이 들어갈 정사각형 빈 칸, 오른쪽에 이름 빈 칸
3. 스크롤 바 (틀 + 손잡이)
4. 이동 버튼 (보통/눌림/비활성), 취소 버튼 (보통/눌림)
5. 깨굴이가 순간이동 포털에서 튀어나오는 작은 장식 (분리)

[스타일]
- 깔끔한 플랫 + 살짝 입체감 있는 캐주얼 게임 UI. 마인크래프트와 어울리게 모서리는 살짝 각진 둥근 사각형
- 크림색 기반 + 하늘색 포인트, 개구리 초록은 깨굴이에게만
- 외곽선은 굵고 단순하게, 그림자는 한 겹만
- 노이즈, 질감, 잔무늬, 반짝이 파티클, 과한 그라데이션 같은 자글자글한 디테일 전부 빼줘
- 면은 단색이나 아주 부드러운 2단 그라데이션까지만
- AI 그림 특유의 과한 광택, 뭉개진 장식, 의미 없는 문양 금지

[중요]
- 글자는 절대 넣지 마. 모든 글자 칸은 빈 공간으로 (게임에서 직접 씀)
- 배경은 투명 또는 단색 회색 단일 배경
- 모든 부품을 상태별로 겹치지 않게 간격 넉넉히 한 시트에 배치, 정면 시점, 원근 없음
```
