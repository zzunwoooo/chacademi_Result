# 마법 200종 효과음 · 소재와 제작 기록

최종 OGG는 아래 CC0 소재를 편집하고 자체 합성음을 혼합해 만든 파생 음원입니다.
원본 소재를 직접 녹음했다고 주장하지 않습니다. 바람 소재는 원저자가 합성한 소리이며, 물 묶음은 녹음과 제작 효과음이 섞인 자료입니다.
외부 음성·노래·상용 게임의 추출 음원은 사용하지 않았습니다.

## 출처

- [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) — Kenney, CC0
- [Kenney RPG Audio](https://kenney.nl/assets/rpg-audio) — Kenney, CC0
- [40 CC0 water / splash / slime SFX](https://opengameart.org/content/40-cc0-water-splash-slime-sfx) — rubberduck, CC0
- [Fire Crackling](https://opengameart.org/content/fire-crackling) — AntumDeluge, CC0
- [wind1](https://lpc.opengameart.org/content/wind1) — Luke.RUSTLTD, CC0

라이선스: https://creativecommons.org/publicdomain/zero/1.0/
2026-09-21 공식/원저자 배포 페이지의 라이선스 표시와 Kenney 원본 License.txt를 확인했습니다.
배포한 개별 파생 OGG와 자체 합성음 기여분도 CC0로 제공합니다.
이는 기존 모드 코드·폰트·아이콘·다른 리소스의 라이선스를 변경하지 않습니다.

## 가공

- 마법별 200개 편집 구성표: recipes.tsv
- 사용 소재 조각 142개, 동작 구성 83가지. 단순 음높이 변경으로 200개를 복제하지 않았습니다.
- 자르기, 순서 재배치, 역재생, 짧은 조각 재조합, 대역 필터, 엔벌로프, 재질별 합성음과 잔향을 사용했습니다.
- 파일별 사용 원본·길이·음량·해시: catalog.json
- 원본 묶음 해시: source-manifest.json
- 최종 파일: mono 32kHz Vorbis OGG, 약 1.3~3초, 200개 합계 약 2.5MB.
- 클라이언트에서 최종 음원은 원래 속도(1.0)로 재생합니다. 음원 편집은 모두 미리 수행하며 게임 실행 중에는 합성하지 않습니다.
- 기존 160종 화면 VFX는 유지하며, 화면 VFX가 아직 없는 40종은 사운드만 연결했습니다.
- 이 자료는 클라이언트 시전 효과음입니다. 실제 서버 스킬의 성공 여부를 확인하는 시스템을 새로 구현하지 않습니다.

## 확인 방법

preview.html에서 200개 효과음을 듣고 이전 소리와 비교할 수 있습니다.
게임에서는 `/sfx 마법명` 또는 `/sfx 영문_ID`로 소리만 재생하고, `/sfx stop`으로 정지합니다.
기존 `/vfx off` 상태에서는 효과음도 재생하지 않으며 `/vfx on`으로 다시 켭니다.
마법 단축키 사용 시에는 기존 권한·쿨타임 검사를 통과한 뒤 소리가 납니다.
빠르게 여러 마법을 쓰면 이전 시전음을 정지하고 새 시전음 하나만 재생합니다.
