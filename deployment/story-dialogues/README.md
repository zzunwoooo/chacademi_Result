# 메인 스토리 1장 대화 파일 (2026-10-26 다시 짜기)

운영 설정 overlay(`tools/operating_overlay.py`)는 스토리 대화를 다루지 않아서 여기에 둔다. 단계표·NPC 정할 곳은 [docs/plans/story-ch1-v2.md](../../docs/plans/story-ch1-v2.md).

## 규칙

- **대화 ID = 단계 ID** (`ch1-12` 단계 → 대화 `ch1-12`). 대기대화는 `<단계>w-<NPC>` (예 `ch1-12w-ole`).
- 분류의 거울은 `ch1-19` (6문항) → 결과 `ch1-19r-/m-/f-<arkeon|lumina|bestiaz|noxer>` — SchoolBridge·스토리 플러그인 상수와 같은 번호 (2026-10-27 ch1-17 → ch1-19, 빌드 필요).
- 대사는 서버가 보낸다 (`chacademy:dialogue_content`). 초상화는 리소스팩 `chacademia_npc` 의 `magiccodex:textures/gui/dialogue/<이름>.png` (대화 파일의 `vl_ole-neutral.png` 같은 이름). **클라이언트에 대화 파일을 따로 넣을 필요 없음.** 새로 쓰는 초상화: `vl_selma-neutral.png` (셀마) — 리소스팩에 없으면 이름만 나옴.
