# 차카데미 운영자 쉬운 안내 (오픈 전 메모 #38, 2026-10-25)

> 코드에 실제로 등록된 명령만 적었습니다. 전체 목록은 [ADMIN_COMMANDS_KO.md](ADMIN_COMMANDS_KO.md).
> **모르면 `/관리`** 를 치세요. 줄을 누르면 채팅창에 명령이 들어갑니다.
> **말로 물어봐도 돼요**: `/관리 질문 돈을 잃었다는 유저가 있어` 처럼 치면 AI 도우미가 쓸 명령을 순서대로 알려 줘요. 명령은 눌러서 채팅창에 넣고 직접 실행해요 (도우미는 실행하지 않음).

## 먼저 알아 둘 5가지
1. 관리 명령은 **OP만** 쓸 수 있어요. OP가 아니면 명령이 아예 안 보여요.
2. 유저는 **한글 닉네임**으로 적어요. 칠 때 회색 글씨(자동완성)가 다음에 넣을 것을 알려 줘요. **Tab 키**로 채우면 돼요.
3. 띄어쓰기가 있는 이름(마법·칭호·물고기)은 **띄어쓰기를 빼고** 적어요. 자동완성도 그렇게 보여 줘요.
4. 지우기·초기화처럼 되돌릴 수 없는 명령은 **끝에 `확인`** 을 붙여야 실행돼요. 안 붙이면 "끝에 '확인'을 붙여…" 알림만 나와요.
5. 오른쪽 아래 알림 + 삐빅 소리 = 실패예요. 알림 글을 읽고 고치면 돼요. **"명령어 사용에 실패했습니다"** 가 나오면 개발자에게 그 시간과 명령을 알려 주세요 (원인은 서버 콘솔에 있어요).

모든 유저 명령은 `/유저관리 <닉네임> …` 으로 시작해요. **`/유저관리 <닉네임>`** 만 치면 그 유저 요약(기숙사·칭호·돈·티어 …)과 할 수 있는 일 목록이 나와요.

## 상황별로 찾기

### 돈·아이템
| 이런 말을 들으면 | 이렇게 |
|---|---|
| "돈을 잃었어요" / "돈이 이상해요" | ① `/유저관리 <닉네임> 돈 보기` 로 확인 ② 돌려줄 만큼 `/유저관리 <닉네임> 돈 추가 <금액>` (빼기는 `돈 빼기`, 딱 맞추기는 `돈 설정`) |
| "상점에서 샀는데 아이템이 안 왔어요" | ① `/유저관리 <닉네임> 거래기록` 에서 끝나지 않은 거래번호 확인 ② `/상점관리 거래처리 <거래번호> 완료`(상품 지급) 또는 `환불`·`취소` |
| "아이템을 하나 줘야 해요" | 그 아이템을 내 손에 들고 `/유저관리 <닉네임> 우편 보내기 <제목>` → 우편함으로 가요 (손에서 빠지는 건 우편 저장이 확인된 뒤) |
| "우편을 받았는데 아이템이 없어요" | `/유저관리 <닉네임> 우편 기록` → 멈춘 수령 번호를 `/유저관리 <닉네임> 우편 처리 <수령번호> 완료` 또는 `반환` |
| "마일리지가 이상해요" | `/유저관리 <닉네임> 마일리지 보기` · `마일리지 기록` · `마일리지 추가 <값>` |
| "장신구(반지·귀걸이·목걸이)가 사라졌어요" | `/유저관리 <닉네임> 장신구 보기` → `장신구 돌려주기 <칸>` (칸 = 아티팩트·반지·귀걸이·목걸이) |
| "배낭 2·3쪽이 안 열려요" | `/유저관리 <닉네임> 배낭 보기` → 확장권을 썼는데 안 열렸으면 `배낭 해금 <쪽수>` |
| "물고기를 팔거나 꺼내다 멈췄어요" | `/유저관리 <닉네임> 낚시 수조 멈춘처리` 로 번호 보기 → 화면 안내대로 처리 |

### 접속·이동
| 이런 말을 들으면 | 이렇게 |
|---|---|
| "서버를 옮겼더니 접속이 안 돼요 (이전 서버가 잠금을 안 풀었대요)" | `/유저관리 <닉네임> 캐릭터잠금 보기` → 잠겨 있으면 `/유저관리 <닉네임> 캐릭터잠금 풀기 확인` (그 유저가 어느 서버에도 접속해 있지 않을 때만) |
| "끼었어요 / 이상한 곳에 갇혔어요" | 내가 가서 보기: `/유저관리 <닉네임> 찾아가기` · 데려오기: `/유저관리 <닉네임> 불러오기` · 좌표로 보내기: `/유저관리 <닉네임> 좌표이동 <x> <y> <z> [월드]` |
| "땅에 떨어져서 다쳤어요 / 배고파요" | `/유저관리 <닉네임> 회복` (체력·배고픔 가득, 불 끄기) |
| 운영자가 날아서 둘러보기 | `/유저관리 <내닉네임> 비행 켜기` (끄기: `비행 끄기`). 빗자루를 타고 있으면 내린 뒤에 |
| 운영자 게임모드 바꾸기 | `/유저관리 <내닉네임> 게임모드 크리에이티브` (서바이벌·크리에이티브·모험·관전) |
| "지도 이동 지점이 안 열려요" | `/유저관리 <닉네임> 이동지점 보기` → `이동지점 해금 <ID>` |

- 찾아가기·불러오기는 **같은 서버**에 있는 유저에게 돼요. 다른 서버에 있으면 HuskHomes가 설치돼 있을 때만 HuskHomes가 대신 옮겨 줘요.
- 큐디치·결투 경기 중인 유저는 순간이동이 막힐 수 있어요 ("순간이동이 막혔어요" 알림).

### 닉네임·기숙사·칭호
| 이런 말을 들으면 | 이렇게 |
|---|---|
| "닉네임을 잘못 정했어요" | `/유저관리 <닉네임> 닉네임 설정 <새닉네임>` (같은 이름이 이미 있으면 거절돼요) |
| "닉네임 창이 안 떠요" | `/유저관리 <닉네임> 닉네임 창열기` (처음부터 다시: `닉네임 다시정하기`) |
| 기숙사를 미리 정해 줄 유저 | `/유저관리 <닉네임> 기숙사 <아르케온|루미나|베스티아즈|노크세르>` (분류 거울에서 창시자 연출) |
| 테스트 계정 기숙사 지우기 | `/유저관리 <닉네임> 기숙사 초기화 확인` |
| "칭호를 받아야 하는데 없어요" | `/유저관리 <닉네임> 칭호 보기` → `칭호 주기 <칭호>` |

### 마법·스토리·퀘스트
| 이런 말을 들으면 | 이렇게 |
|---|---|
| "마법을 발견했는데 안 배워졌어요" | `/유저관리 <닉네임> 마법 배우기 <마법>` (잊게 하기: `마법 잊기`) |
| "마법 쿨타임이 안 끝나요" | `/유저관리 <닉네임> 마법쿨타임 보기` → `마법쿨타임 초기화` |
| "스토리가 멈췄어요 / 다음으로 안 넘어가요" | ① `/유저관리 <닉네임> 스토리진행 보기` ② 조건을 채웠는데 멈췄으면 `스토리진행 다음` ③ 이 단계 시작부터 다시 보여 주기 `스토리진행 다시` |
| "대화창이 안 닫혀요 / 스토리가 계속 떠요" | `/대화관리 중지 <닉네임>` (끝 명령은 실행 안 함) |
| "의뢰 보상을 못 받았어요" | `/유저관리 <닉네임> 의뢰기록 보기` → 화면의 처리 명령 |
| "NPC 호감도가 이상해요" | `/유저관리 <닉네임> 호감도 <NPC> 보기` → `설정|추가|빼기 <값>` |
| 다음 장 공개하기 | `/대화관리 장공개 목록` → `/대화관리 장공개 열기 <장번호>` (다시 잠그기: `장공개 잠그기 <장번호>`) |

### 일러스트·아티팩트·뽑기
| 이런 말을 들으면 | 이렇게 |
|---|---|
| "내 일러스트가 안 나와요 / 이상해요" | `/유저관리 <닉네임> 초상화 보기` → 관리자가 다시 그리기: `초상화 다시그리기` |
| "재생성권을 썼는데 실패했어요" | 정책: **실패해도 재생성권은 소모**돼요 (입력창에 안내됨). 그림 시작 전에 멈춘 것은 자동으로 돌아가요. 확인: `/유저관리 <닉네임> 초상화 재생성권 보기`. 운영자가 특별히 돌려주기로 했을 때만 `/유저관리 <닉네임> 초상화 환불` (소모된 1건을 돌려줌, 재생성권을 쓴 그 서버에서) |
| "아티팩트 뽑기를 했는데 안 받았어요" | `/유저관리 <닉네임> 아티팩트 뽑기기록 보기` → `뽑기기록 다시주기 <번호>` 또는 `완료처리 <번호>` |
| "튼튼한 끈이 지켜 준 아이템을 못 받았어요" | `/유저관리 <닉네임> 아티팩트 보관품돌려주기` |

### 큐디치·결투·파티

|---|---|

## 테스트용 (`/테스트 …`, 운영 중 유저에게 쓰지 마세요)
- `/테스트 마법 시전 <마법>` — 마법 하나 시전
- `/테스트 마법 자동시전 [시작 [도감번호|마법]|정지|일시정지|재개|건너뛰기|간격 <초>|상태]` — 모든 마법을 차례로 내가 시전 (마나·쿨타임 무시, 점검용)
- `/테스트 스토리 <대화|컷신> <ID> [닉네임]` — 이미 본 것도 다시 보기 (보상 없음)
- `/테스트 화면 알림 <정보|경고|실패|보상>` — 알림 모양 보기
