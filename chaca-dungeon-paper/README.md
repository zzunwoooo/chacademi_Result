# ChacaDungeon — 1인 던전 (리치의 지하 연구실)

신기능 세션 작업, 브랜치 `feature/dungeon-lich-20261029`. **서버 반영·재시작은 하지 않았다** (규칙 세우기 세션 + 오너 승인 뒤 정기 점검 때).

## 한눈에

- 학교 서버 `dungeon1` 월드. 던전 하나에 **독립 칸 3개**(오너가 맵을 복사해 둔 자리), 칸마다 1명. 다 차면 **대기열(등록 순서)**.
- 새 서버를 만들지 않는다. 나중에 던전 서버로 옮길 때는 같은 플러그인을 그 서버에 두고 포탈 쪽만 서버 이동으로 바꾸면 된다
  (기록은 공용 MariaDB 라 그대로).
- 파티는 건드리지 않는다: 입장은 언제나 본인 혼자이고, 파티 탈퇴·동반 이동 없음. 파티에 있어도 입장 가능.
- 화면은 새 클라이언트 모드 `chacademi-dungeon` (런처에 추가). 기존 MagicCodex·스토리 모드 jar 는 **바꾸지 않았다** (리플렉션으로만 연결).
- ChacaGimmick·MagicCodexBridge jar 도 바꾸지 않았다 (기믹 상태·초기화, 보상 전달, 닉네임은 리플렉션).

## 흐름

1. **포탈**: `/던전관리 포탈` 로 찍은 자리에 보라색 홀로그램(스토리 목표 포탈과 같은 그림) + 던전 이름. 반경 안에 들어오면 입장창이 열린다.
   같은 자리에 서 있는 동안은 다시 열리지 않고, 반경 × 1.6 밖으로 나갔다가 다시 오면 열린다. 다른 창(대화·상점 등)이 떠 있으면 덮지 않고 기다린다.
2. **입장창**: 이름·일러스트·1인 전용·클리어 여부·내 최고 기록·서버 최고 기록·보유자 한글 닉네임·그 아래 접두+접미 칭호(오프라인이어도 DB)·
   보상 칸(실제 아이템 렌더러, 툴팁, 많으면 휠 스크롤)·진행 중 n / 3·입장권. 버튼: 자리 있음 → 입장하기 / 꽉 참 → 대기열 등록 / 대기 중 / 입장 준비 완료 / 잠김.
   - 2장 ch2-21 에 도달하지 않았으면 잠김 ("2장 이야기를 진행하면 열려요").
   - 보상 칸은 첫 클리어 전이면 첫 클리어 보상, 그 뒤엔 반복 보상.
3. **대기열**: 등록 때 입장권을 걷지 않는다. 내 순서·진행 중 칸 수·대기 인원, "대기 취소". 창을 닫아도 대기는 유지.
   자리가 나면 맨 앞 사람에게 그 칸을 잡아 두고 알림 + "입장 준비 완료" 창 (60초).
4. **입장** (버튼 → 서버가 다시 확인): 세션 번호·권한·도전 중 아님·칸·입장권을 서버가 다시 본다. 연타·중복 패킷은 busy 표시로 한 번만 처리,
   입장권은 칸을 잡은 같은 틱에 한 번만 걷는다. 이동이 실패하면 입장권을 돌려주고(가방, 넘치면 우편) 칸을 정리한다.
   **첫 클리어 전에는 입장권 없이** (스토리 첫 입장), 그 뒤 1장.
5. **던전 안**: 오른쪽 위 던전 메뉴(이름·경과 시간·나가기). 오른쪽에 은색 던전 단계창 (스토리 퀘스트창과 같은 모양, 스토리 퀘스트는 그대로 따로 보임).
   - **도전 시작 = 시작 지점에 도착한 뒤 처음 움직였을 때** (움직이지 않으면 10초 뒤). 이동·로딩 시간은 기록에 안 들어감.
   - 시간은 서버가 잰다 (클라는 받은 값에 흐른 시간을 더해 보여 줄 뿐, 5초마다 다시 맞춤). 창을 닫거나 HUD 를 숨겨도 그대로. 제한 시간·시간 초과 실패 없음.
   - 나가기 버튼은 채팅창이나 Ctrl 포인터 화면에서 누른다 (평소에 커서를 붙잡지 않음). → 확인창 "계속 도전 / 나가기".
6. **단계** (dungeons.yml): room(방 몹 전부 처치) · kill(몹 n마리) · boss(단계 시작 때 소환, 처치) · gimmick(기믹이 열림) · reach(지점 도착).
   이벤트는 그 판의 칸·그 판의 현재 단계에만 센다 (다른 사람·다른 칸·지난 단계 이벤트는 무시).
   **방**: 들어가는 순간 그 칸에만 몹 소환, 가두기 켜져 있으면 다 잡을 때까지 방 밖으로 못 나감(걷기·순간이동 모두).
7. **끝**: 마지막 단계 완료 = 클리어 → 기록 확정·비교·갱신 → 보상(서버가 클리어 판정 때 지급, 판 번호로 한 번만) → 결과창.
   결과창: 이번 기록·이전 개인 기록·서버 최고(닉네임·칭호)·**실제로 준 아이템**·지급 방법(가방/우편/발밑).

## 끝나는 경우 정리

| 경우 | 처리 |
|---|---|
| 클리어 | 기록·보상·클리어 명령(`유저관리 {player} 스토리신호 던전클리어`) → 포탈 앞으로 → 결과창 |
| 나가기 (중도 포기) | 실패. 기록·보상·환불 없음. 포탈 앞으로 |
| 사망 | 실패. **아이템·경험치 유지** (던전 월드 전체). 포탈 앞에서 부활, 부활 뒤 결과창 |
| 접속 종료 / 서버 이동 | 실패 (재접속 유예 없음). 나가는 순간 포탈 앞으로 옮김. 다시 접속했는데 던전 월드면 포탈 앞으로 |
| 다른 방법으로 던전 월드를 벗어남 (귀환권 등) | 실패 |
| 이동 중 실패 (입장 직후) | 판 취소, 입장권 반환 |
| 플러그인 종료·재시작 | 진행 중 판 전부 실패, 포탈 앞으로, 칸 즉시 정리 |
| 운영진 `/던전관리 강제퇴장` · `칸초기화` | 실패 처리 후 정리 |

**칸 정리** (끝난 다음 틱, 청크가 아직 불러와져 있을 때): 이 판에서 소환한 몹, 구역 안의 떨어진 아이템·경험치·투사체·적대 몹 제거 +
구역 안 기믹 초기화 (`/던전관리 초기화` 와 같은 동작). 성공해야 FREE → 다음 대기자에게 배정. 실패하면 BROKEN (배정 안 함, 콘솔 로그, `칸초기화` 로 재시도).
소환 몹은 `setPersistent(false)` 라 청크가 내려가도 디스크에 남지 않는다. 도착할 때도 한 번 더 정리한다.
던전 월드: 블록 부수기·놓기·양동이·아이템 떨구기 금지 (`chacademi.dungeon.build` 권한은 예외 — 맵 작업용).

## 기록 DB (공용 MariaDB, 없으면 이 폴더 records.db)

- `codex_dungeon_record(dungeon, player, clears, best_ms, best_at, first_at)` — 개인 기록. 서버 최고 = best_ms 가장 작은 줄.
- `codex_dungeon_run(run_id UNIQUE, …, result, time_ms, first_clear)` — 판 장부. 클리어는 run_id 를 먼저 넣고 성공했을 때만 기록·보상 → 중복 이벤트·재접속에도 한 번만.
- 보유자 닉네임 = `codex_nicknames`, 칭호 = `codex_title_player` (같은 공용 DB) + titles.yml 이름·색.
- DB 작업은 전용 스레드 하나, 연결 하나 (플레이어별 연결 없음, 메인 스레드에서 안 기다림).

## 반영 순서 (규칙 세우기 세션, 정기 점검)

1. 서버: `chaca-dungeon-paper/build/libs/chaca-dungeon-0.1.0-lich-20261029.jar` → 학교 `plugins/`. (새 플러그인이라 재시작 필요, 다른 jar 는 그대로)
2. 학교 `ChacademyStory/steps.yml` 의 ch2-21·ch2-22 시작명령 (2장 반영과 같이).
3. 클라: `client-mods/chacademi-dungeon/build/libs/chacademi-dungeon-0.1.0-lich-20261029.jar` → 런처 distribution.json 모드 추가 (release asset + MD5/size).
   스토리 모드(chaca_story)의 포탈·퀘스트 그림과 MagicCodex 글꼴을 빌려 쓴다 (둘 다 이미 설치됨, 없으면 그 부분만 안 그림).
4. 재시작 뒤 확인: 콘솔 `기록 DB: MariaDB …`, `던전 n개 읽음`, 시작 로그 거부 항목 점검.
5. 오너 인게임 설정 (위 순서) → `/던전관리 설정확인` 이 칸 3개 모두 ✔.

## 확인한 것 / 못 한 것

- ✔ 서버 플러그인·클라 모드 빌드 성공 (Paper API 1.21.4, Fabric 1.21.4 Mojang 매핑).
- ✔ 단위 시험 7개 통과: 3명이 서로 다른 칸 → 4번째는 바로 못 들어가고 대기열, 정리 중인 칸은 배정 안 함 → 정리 끝나면 4번째에게 그 칸,
  중복 등록 불가(다른 던전 포함), 대기자가 있으면 포탈 바로 입장 불가, 접속 안 한 대기자 건너뜀·안내 만료, 대기 취소 시 칸 반환, 메시지 왕복, 구역 판정.
- ✔ 배포된 ChacaGimmick·MagicCodexBridge jar 를 javap 로 보고 리플렉션 대상(Gimmick 필드, world()/signals()/reset, RewardDelivery.give, nicknameOf, ChacaApi) 이름·형식이 맞는지 확인.
- ✘ **게임 안 시험은 안 함** (실서버 반영 전). 실제 3명 입장·연타·보상 1회·화면 배치·포탈 그림·은색 단계창은 반영 뒤 확인 필요.
